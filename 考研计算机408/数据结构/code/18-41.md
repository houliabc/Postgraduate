（1）定义一个长度为n的数组A，并将每个元素位置初始化为0。接着从头开始遍历题目的数组nums，如果元素值为负数则跳过，否则将其对应元素值当做下标，将数组A对应的元素值置为1。遍历完后从数组A开始遍历，找到第一个元素值为0的元素，并返回其下标
（2）
```c
int getMinNum(int nums[], int n) {
    int A[n+1]; 
    for(int i=0;i<n+1;i++) A[i]=0;
    for(int i=0;i<n;i++) {
        if (nums[i] <= 0 || nums[i] > n) continue;
        A[nums[i]] = 1;
    }
    // 下标从1开始，排除0
    for(int i=1;i<n+1;i++) {
        if (A[i] == 0) return i;
    }
    return n+1;
}
（3）时间复杂度为O（n），空间复杂度为O(n)
