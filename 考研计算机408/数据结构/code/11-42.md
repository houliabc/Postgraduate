（1）用两个指针指向两个数组的开始位置，依次进行比较，每次将小的一边的指针往后移，当移动了L-1次后，对应指针元素值最小的即是中位数
（2）
```c
int getmedium(int S1[], int S2[], int L) {
    int i = 0, j = 0;
    for (int k = 0; k < L-1; k++) {
        if (S1[i] < S2[j])
            i++;
        else
            j++;
    }
    // 移动移动了L-1次后，对应指针元素值最小的即是中位数
    return S1[i] < S2[j] ? S1[i] : S2[j];
}
（3）时间复杂度O(n)，空间复杂度O(1)
