（1）从根结点开始遍历这颗二叉树，具体处理步骤如下：如果当前结点数叶子结点，则累加当前结点weight*路径长度到WPL里，如果有左孩子则先序遍历左孩子，并将路径长度+1；如果有右孩子则先序遍历右孩子，并将路径长度+1。遍历完成树后的WPL就是所有叶结点的带权路径长度之和

// 初始传入path为0
// 先序遍历求wpl
int getWPL(node *root, int path) {
    // 空树
    if (!root)  return 0;
    // 如果是叶子结点，则累加wpl
    if (!root->left && !root->right)
        return root->weight * path;
    // 若有左右子树，则分别先序遍历左右子树
    return getWPL(root->left, path + 1) + getWPL(root->right, path + 1);
}
