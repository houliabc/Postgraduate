传入参数root和路径长度path（初始为0），首先判断root是否是空树，如果是空树则返回0；若不是，则判断该结点是否是叶子结点，是的话就返回该结点的带全路径长度，如果不是的话就返回左右子树对应的带权路径长度之和，通过递归的方式，就能得到最终的WPL值
（2）
```c
typedef struct node {
    unsigned int weight;
    node *left;
    node *right;
} node;
（3）
int getWPL(node *root, int path) {  // 初始时传入path = 0
    if (!root) return 0;
    // 如果是叶结点
    if (!root->left && !root->right)
        return path * root->weight;
    // 如果不是叶结点，就求左右子树对应的WPL长度之和
    else
        return getWPL(root->left, path + 1) + getWPL(root->right, path + 1);
}
