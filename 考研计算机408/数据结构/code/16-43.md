（1）对集合A进行快速排序，接着循环从表头和表尾各拿一个元素，分别放到A1（存放值小的元素）和A2（存放值大的元素）中，接着再去拿下一个元素（向表中移动），当集合A个数是奇数个时，A2个数要比A1多一个，划分完毕就是满足题目的最优划分算法
（2）
```c
void partition(int A[], int n) {
    int low = 0, high = n - 1 , m = n / 2;
    // 快速排序
    sort(A);
    // 划分子集A1和A2
    int A1[m], A2[n - m];
    for(int i = 0; i < m; i++) {
        A1[i] = A[low++];
        A2[i] = A[high--];
    }
    // 如果是奇数，则A2子集比A1多一个
    if (n % 2 == 1)
        A2[m] = A[high];
}
（3）时间复杂度O（nlogn），空间复杂度O（n）
