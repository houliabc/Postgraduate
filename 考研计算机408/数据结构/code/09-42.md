（1）和（2）（懒得写了，和最新考题不一样）初始化快慢指针，慢指针为头指针，快指针为头指针的后k个位置上，让快慢指针同时往后移动，当快指针是空结点时，此时慢指针就是倒数第k个结点，返回1并输出data值；若k<=0或链表长度小于k，则返回0
（3）
```c
int findK(LNode *list, int k) {
    LNode *slow = list, *fast = list;
    // 判断k是否合规且先让fast向后移动k-1个位置
    if (k <= 0 || list == NULL || list->link == NULL)
        return 0;
    int i = 0;
    for (; i < k && fast; i++) {
        // 前面已校验过确保不会出现访问空结点的link
        fast = fast->link;
    }
    // 表示链表长度＜k
    if (i != k) {
        return 0;
    }
    // slow和fast同时往后，当fast为空时，就是目标结点
    while (fast) {
        fast = fast->link;
        slow = slow->link;
    }
    // 此时slow指向题目要求的结点
    // 输出
    printf("%d", slow->data);
    return 1;
}
时间复杂度O（n），空间复杂度O（1）
