（1）
定义一个长度为n的数组，数组元素全部初始化为0，数组的每个元素代表对应下标值元素在数组中出现的个数。接着遍历数组A，对A的每一个元素，将其对应的位置个数+1，若该个数>n/2，则说明它是主元素，输出该元素，否则遍历完数组都没有出现个数>n/2的情况说明没有主元素，输出-1
（2）
```c
void getMain(int A[], int n) {
    int count[n];
    for(int i = 0; i < n; i++) count[i]=0;
    for(int i = 0; i < n; i++) {
        count[A[i]]++;
        if (count[A[i]] > n/2) {
            printf("%d", A[i]);
            return;
        }
    }
    printf(-1);
    return;
}
（3）时间复杂度O（n），空间复杂度O（n）
