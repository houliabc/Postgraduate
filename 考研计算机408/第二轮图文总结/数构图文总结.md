# 第一章：基本概念 / 第一章：基本概念

## 数据结构的基本概念

### 数据（Data）

数据是信息的载体，是描述客观事物属性的数、字符及所有能输入到计算机中并被计算机程序识别和处理符号的集合

比如：

- 数学中用到的整数和实数
- 文本编辑中用到的字符串
- 我们在电脑或者手机上，看到的图像、声音及动画等，都是通过特殊编码定义后的数据

数据是计算机程序加工的原料

### 数据元素（Data Element）

<span style="color:rgb(255, 0, 0);text-decoration:underline"><span style="color:rgb(255, 0, 0)">**<span style="font-weight:bold;color:rgb(255, 0, 0);text-decoration:underline">数据元素是数据的基本单位</span>**</span></span>，通常作为一个整体进行考虑和处理，用于完整的描述一个对象，有些情况下，数据元素也简称为元素、记录等

比如，下面都可以称为一个数据元素：

- 整数 5
- 单词 data

不过，<span style="text-decoration:underline">**<span style="font-weight:bold;text-decoration:underline">一个数据元素可由若干数据项组成</span>**</span>**<span style="font-weight:bold">，这种数据元素也可以称为</span>****<span style="font-weight:bold">复合数据元素</span>**，比如一个学生的信息记录也是一个数据元素，不过它一般由学号、姓名、性别等多个**<span style="font-weight:bold">数据项</span>**组成

<span style="color:rgb(255, 0, 0);text-decoration:underline"><span style="color:rgb(255, 0, 0)">**<span style="font-weight:bold;color:rgb(255, 0, 0);text-decoration:underline">数据项（Data Item）是构成数据元素的不可分割的最小单位</span>**</span></span>

### 数据对象（Data Object）

**<span style="font-weight:bold">数据对象是具有相同性质的数据元素的集合</span>**，是数据的一个子集

例如：

- 整数数据对象是集合 N = {0，±1，±2，…}
- 字母字符数据对象是集合 C = {‘A’，‘B’，…，‘Z’，‘a’，‘b’，…，‘z’}
- 学生基本信息表也可以是一个数据对象。学生基本信息表中包含了若干个学生的基本信息

由此可以看出，不论数据元素集合是无限集（如整数集），或是有限集（如字母字符集），还是由多个数据项组成的复合数据元素（如学生表）的集合，只要集合内元素的性质均相同，都可称之为一个数据对象

### 数据结构（Data Structure）

<span style="color:rgb(255, 0, 0);text-decoration:underline"><span style="color:rgb(255, 0, 0)">**<span style="font-weight:bold;color:rgb(255, 0, 0);text-decoration:underline">数据结构是相互之间存在一种或多种特定关系的数据元素的集合</span>**</span></span>，换句话说，数据结构是带 “结构” 的数据元素的集合，“结构” 就是指数据元素之间存在的关系

<span style="color:rgb(255, 0, 0);text-decoration:underline"><span style="color:rgb(255, 0, 0)">**<span style="font-weight:bold;color:rgb(255, 0, 0);text-decoration:underline">数据结构包括三方面的内容：逻辑结构、存储结构和数据的运算</span>**</span></span>。这也是数据结构的三要素

### 1. 逻辑结构

数据的逻辑结构是从逻辑关系上描述数据，它与数据的存储无关，是独立于计算机的。数据的逻辑结构有两个要素：一是数据元素；二是关系。数据元素的含义如上面所述，关系是指数据元素间的逻辑关系

根据数据元素之间关系的不同特性，通常有四类基本结构，它们的复杂程度依次递进：

**<span style="font-weight:bold">① 集合结构：数据元素之间除了 “属于同一集合”的关系外，别无其他关系</span>**。例如，确定一名学生是否为班级成员，只需将班级看做一个集合结构

**<span style="font-weight:bold">② 线性结构：数据元素之间存在一对一的关系</span>**。例如，将学生信息数据按照其入学报到的时间先后顺序进行排列，将组成一个线性结构

其中集合结构是一种数据元素之间关系极为松散的结构，一般而言可以用其他的数据结构来表示（比如，可以用树形结构来表示集合结构，因为在树形结构中的每个数据元素都属于同一个树形结构这个集合），所以，我们后续学的数据结构一般都是指线性结构、树形结构和图结构这三种

我们通常将上述四种结构划分为线性结构和非线性结构两类，线性结构包括：

- 线性表：典型的线性结构，如前面的学生基本信息表
- 栈和队列：具有特殊限制的线性表，数据操作只能在表的一端或两端进行
- 字符串：也是特殊的线性表，其特殊性表现在它的数据元素仅由一个字符组成
- 数组：是线性表的推广，它的数据元素是一个线性表
- 广义表：也是线性表的推广，它的数据元素是一个线性表，但不同构，即或者是单元素，或者是线性表

非线性结构包括：

- 集合结构
- 树：具有多个分支的层次结构
- 二叉树：具有两个分支的层次结构
- 有向图：一种图结构，边是顶点的有序对
- 无向图：一种图结构，边是顶点的无序对

### 2. 存储结构

数据对象在计算机中的存储表示称为数据的存储结构，也称为物理结构。把数据对象存储到计算机时，通常要求既要**<span style="font-weight:bold">存储各数据元素的数据</span>**，又要**<span style="font-weight:bold">存储数据元素之间的逻辑关系</span>**

数据元素在计算机中有两种基本的存储结构，分别是顺序存储结构和链式存储结构

#### 2.1. 顺序存储结构

举个例子，一个线性结构 （2, 5, 3, 9, 6），该如何存储在内存中呢？首先，你要确定每个数据元素，需要多大内存，假设这里的每个整数，需要 2 个字节的内存，这样，我们只要找出 10 个字节的空闲内存，就可以存储：

![图片](http://wechatapppro-1252524126.cdn.xiaoeknow.com/appvpmptkl94774/image/default/cAKqeiI1769047880MF.png?imageView2/2/q/100|imageMogr2/ignore-error/1)

这里每一格可以存储 2 字节的数据，当然，这些数据都是以二进制形式存储在内存中

但是，这里没有表示出数据元素之间的线性关系，线性关系是一对一的，当你知道第一个元素，就可以找到第二个元素，当你找到第二个元素，就可以找到第三个元素，这样按照顺序找下去，可以找到所有的元素，要表示这种线性关系，最简单的方式，就是将所有元素，按照顺序紧挨着，存储在内存中：

![图片](http://wechatapppro-1252524126.cdn.xiaoeknow.com/appvpmptkl94774/image/default/cQuXbBp1769047880wG.png?imageView2/2/q/100|imageMogr2/ignore-error/1)

这样，当我们通过内存地址 0x0632 找到第一个元素 2 后，然后根据简单的地址计算，就可以很快的访问到第二个元素，第三个元素

这种存储的特点是：**<span style="font-weight:bold">借助元素在存储器中的相对位置，来表示数据元素之间的逻辑关系</span>**，**<span style="font-weight:bold">这种存储方式，我们称之为顺序存储结构</span>**

在高级编程语言中，数组是对顺序存储结构的抽象，这样，我们就不用关心顺序存储的内存细节了（就是说，我们不用真的用内存地址去访问元素了，而是通过下标直接访问），如下图：

![图片](http://wechatapppro-1252524126.cdn.xiaoeknow.com/appvpmptkl94774/image/default/cYrh8lp1769047880GZ.png?imageView2/2/q/100|imageMogr2/ignore-error/1)

变量 a ，本质上就是数组第一个元素在内存中的地址，通过下标访问元素，本质就是通过地址计算，来访问元素

#### 2.2. 链式存储结构

顺序存储结构要求所有的元素依次存放在一片连续的存储空间中，而链式存储结构，无需占用一整块存储空间。**<span style="font-weight:bold">链式存储结构，是借助数据对象存储的内存地址，来表示数据对象之间的逻辑关系</span>**

比如，对于线性结构 （2, 5, 3, 9, 6）：

![图片](http://wechatapppro-1252524126.cdn.xiaoeknow.com/appvpmptkl94774/image/default/cS8IlyG176904788010.png?imageView2/2/q/100|imageMogr2/ignore-error/1)

所有的元素，可以在内存中的任意空闲位置存储，不过，在每个元素后面，再存储这个元素的下一个元素在内存中的地址，这样，当我们知道第一个元素的内存地址后，就可以根据第一个元素后面的内存地址，去访问第二个元素，同样，根据第二个元素后面的内存地址，去访问第三个对象，依次类推，就可以访问所有的元素，这样，也表示了线性结构关系

在这里，对于每个元素，不单单要存储数据本身，还需要存储下一个数据对象的内存地址，这个内存地址，可以通过 C 语言中的指针来实现，在高级语言中，我们可以通过定义 Node 这个结构体，来抽象的表示每一个元素：

### 3. 数据的运算

指对数据结构中的元素进行的各种运算（操作），包括插入、删除、查找、修改等，不同的数据结构支持不同的操作，比如对于线性表，常见的操作有：

- 在指定的位置插入一个元素
- 删除指定位置的元素
- 查找某个元素
- .....

思考一个问题：**<span style="font-weight:bold">如果两个数据结构，它的逻辑结构和存储结构是一样的，那么这两个数据结构就一定一样吗？</span>**

答：不一定。注意，**<span style="font-weight:bold">数据的运算也是数据结构三要素之一</span>**

对于两种不同的数据结构，它们的逻辑结构和物理结构完全有可能相同。比如栈和队列，它们的逻辑结构都属于线性结构，都可以使用顺序存储，但是他们支持的操作各不同，所以这两个数据结构是不同的，如下图：

## 数据类型

> 本篇文章对应的视频课程是：【[<span style="color:rgb(20, 114, 255)">数据结构</span>](https://xe6hm.xetlk.com/s/2Q6PEi)】的第一章 09 这 1 小节

数据类型（Data Type）是高级程序设计语言中的一个基本概念，前面提到过使用**<span style="font-weight:bold">数组</span>**来描述顺序存储结构，使用**<span style="font-weight:bold">指针</span>**来描述链式存储结构，而数组和指针都是 C 语言中的数据类型，所以说数据类型和数据结构之间关系密切

可以这么说：数据结构更多的是抽象层面的，而数据类型是具体实现层面上的，每一种数据结构都可以由某种编程语言中的某一种数据类型来实现

实际上，在后面，我们也会使用每一种具体的数据类型，来实现每个对应的数据结构

### 数据类型

在写 C 程序时，每个数据（变量）都属于某种数据类型，数据类型明显或隐含地规定了数据的**<span style="font-weight:bold">取值范围</span>**、**<span style="font-weight:bold">存储方式</span>**以及**<span style="font-weight:bold">允许进行的运算，数据类型是一个值的集合和定义在此集合上的一组操作的总称</span>**

例如：C 语言中的整型（int）变量，其值集为某个区间上的整数（比如 int 占用 4 字节的话，那么它的整数区间就是 -2<sup>31</sup> ~ 2<sup>31</sup> - 1），定义在其上的操作为加、减、乘、除和取模等算术运算；而实型（float、double）变量也有自己的取值范围和相应运算，比如取模运算是不能用于实型变量的

按 “值” 的不同特性，高级程序语言中的数据类型可分为两类：

- 一类是非结构的原子类型。原子类型的值是不可分解的，例如 C 语言中的基本类型 (整型、实型、字符型和枚举类型)、指针类型和空类型
- 另一类是结构类型。结构类型的值是由若干属性按某种结构组成的，因此是可以分解的，并且它的属性可以是非结构的，也可以是结构的

比如，数组就是结构类型，数组的每个元素就是数组的每个属性，数组元素可以是 int 类型（非结构类型），也可以是 Student 这种结构类型，如下程序代码：

引入 “数据类型” 的目的，从硬件的角度看，是**<span style="font-weight:bold">作为解释计算机内存中信息含义的一种手段</span>**，而对使用数据类型的用户来说，实现了信息的隐蔽，即将一切用户不必了解的细节都封装在类型中

例如，用户在使用 “整数” 类型时，既不需要了解 “整数” 在计算机内部是如何表示的，也不需要知道其操作是如何实现的。如 “两整数求和”，程序设计者注重的仅仅是其 “数学上求和” 的抽象特性，而不是其硬件的 “位” 操作如何进行

当我们要使用一种数据结构时，我们可以先通过 ADT 来定义它的数据对象、数据关系以及基本操作，这时，我们不需要去关系它的具体实现，我们可以基于 ADT 中提供的基本操作来解决具体的问题，ADT 中的基本操作也可以称为<span style="color:rgb(255, 0, 0)"><span style="color:rgb(255, 0, 0)">**程序编程接口（Application Program Interface，简称 API）**</span></span>，**<span style="font-weight:bold">这种将接口和具体实现分开，是一种经典的编程思想，它的好处就是：可以在很少修改代码（甚至不修改代码）的情况下，使用另一种具体实现来代替一种具体实现，提高了代码的可扩展性</span>**

接下来，再来看一个关于**<span style="font-weight:bold">复数</span>**的例子

形如 a+bi（a、b均为实数）的数为复数，其中，a 被称为[实部](https://baike.baidu.com/item/%E5%AE%9E%E9%83%A8/53626919?fromModule=lemma_inlink)，b 被称为虚部，i 为[虚数](https://baike.baidu.com/item/%E8%99%9A%E6%95%B0/107344?fromModule=lemma_inlink)单位

复数通常用 z 表示，即 z=a+bi，当 z 的虚部 b＝0 时，则 z 为[实数](https://baike.baidu.com/item/%E5%AE%9E%E6%95%B0/296419?fromModule=lemma_inlink)；当 z 的[虚部](https://baike.baidu.com/item/%E8%99%9A%E9%83%A8/5231815?fromModule=lemma_inlink) b≠0 时，实部 a＝0 时，常称 z 为[纯虚数](https://baike.baidu.com/item/%E7%BA%AF%E8%99%9A%E6%95%B0/3386848?fromModule=lemma_inlink)

## 算法的基本概念

> 本篇文章对应的视频课程是：【[<span style="color:rgb(20, 114, 255)">数据结构</span>](https://xe6hm.xetlk.com/s/2Q6PEi)】的第一章 11 这 1 小节

算法（Algorithm）是为了解决某类问题而规定的一个有限长的操作序列，比如下面是用 C 语言实现的简单插入排序算法

![image/png](https://wechatapppro-1252524126.cdn.xiaoeknow.com/appvpmptkl94774/image/b_u_61a2357cb8665_QQ2rVIin/9obvbhmkovlw25.png?imageView2/2/q/100|imageMogr2/ignore-error/1)

上面算法中的每条语句，我们也可以称为一个操作，也可以称为一个指令；所以说上面的简单插入排序算法是对数组进行升序排列的一个有限长的操作序列

一个算法还具有下列五个重要特性：

1. **<span style="font-weight:bold">有穷性：</span>**一个算法必须总是在执行有穷步后结束，且每一步都必须在有穷时间内完成
2. **<span style="font-weight:bold">确定性：</span>**算法中每条指令必须有确切的含义，对于相同的输入只能得出相同的输出
3. **<span style="font-weight:bold">可行性：</span>**算法中描述的操作都可以通过已经实现的基本运算执行有限次来实现
4. **<span style="font-weight:bold">输入：</span>**一个算法有零个或多个输入，这些输入取自于某个特定的对象的集合
5. **<span style="font-weight:bold">输出：</span>**一个算法有一个或多个输出，这些输出是与输入有着某种特定关系的量

通常，设计一个 “好” 的算法应考虑达到以下目标：

1. **<span style="font-weight:bold">正确性：</span>**在合理的数据输入下，能够在有限的运行时间内得到正确的结果
2. **<span style="font-weight:bold">可读性：</span>**算法应具有良好的可读性，以帮助人们理解
3. **<span style="font-weight:bold">健壮性：</span>**当输入的数据非法时，好的算法能适当地做出正确反应或进行相应处理，而不会产生一些莫名其妙的输出结果
4. **<span style="font-weight:bold">高效性：</span>**高效性包括时间和空间两个方面

**<span style="font-weight:bold">时间复杂度和空间复杂度是衡量算法的两个主要指标，这是这一章的重点，我们下一节详细讲解</span>**

- 若某个算法的输入是一个图，则输入规模 n 就可以用该图中的定点数和边数来描述

### 程序执行时间

一个程序的执行时间大致上等于其所有语句执行时间的总和，而**<span style="font-weight:bold">语句的执行时间则为该条语句的重复执行次数和执行一次所需时间的乘积</span>**，一个语句重复执行的次数，称为**<span style="font-weight:bold">语句频度</span>**

由于语语句执行一次实际所需的具体时间是与机器的软、硬件环境（如机器速度、编译程序质量等）密切相关的。所以，所谓的算法分析并非精确统计算法实际执行所需时间，而是针对程序中语句的执行次数做出估计，从中得到程序执行时间的信息，**<span style="font-weight:bold">假设每条语句执行一次所需的时间均是单位时间</span>**，则一个程序的执行时间可用该算法中所有语句频度来度量

来看一个程序：

![image/png](https://wechatapppro-1252524126.cdn.xiaoeknow.com/appvpmptkl94774/image/b_u_61a2357cb8665_QQ2rVIin/q7y5o5mkovp241.png?imageView2/2/q/100|imageMogr2/ignore-error/1)

上面程序所有语句频度为：(n + 1) + n * (n + 1) + n * n = 2n^2 + 2n + 1

我们将算法中所有语句频度记为 f(n)，也就是 f(n) = 2n^2 + 2n + 1，它是该算法输入数据规模 n 的一个函数，那么，上面算法的执行时间就与 f(n) 成正比，因为我们前面做过假设：**<span style="font-weight:bold">每条语句执行一次所需的时间均是单位时间</span>**

### 时间复杂度的定义

从前面可以看出：算法的执行时间是随输入数据规模（n）增长而增长的，因此对算法的评价通常只需考虑其随问题规模增长的趋势，这种情况下，我们只需要考虑当输入数据规模（n）充分大时，算法中语句的执行次数在渐近意义下的阶。如前面例子矩阵的和算法，当 n 趋向无穷大时，显然有：

![图片](http://wechatapppro-1252524126.cdn.xiaoeknow.com/appvpmptkl94774/image/default/cekn28S1769051733LA.png?imageView2/2/q/100|imageMogr2/ignore-error/1)

即当 n 充分大时，f(n) 和 n<sup>2 </sup>之比是一个不等于零的常数。即 f(n) 和 n<sup>2</sup> 是同阶的，或者说 f(n) 和 n<sup>2</sup>  的数量级相同。在这里将 f(n) 的最高阶系数、低阶和常量都去掉，得到函数 g(n) = n<sup>2</sup>，在这里，我们用 “O” 来表示数量级，记作 T(n) = O(g(n)) = O(n<sup>2</sup> )

由此我们可以给出下述算法时间复杂度的定义。**<span style="font-weight:bold">一般情况下，算法中语句</span>****<span style="font-weight:bold">频度</span>****<span style="font-weight:bold">是输入数据规模 n 的某个函数 f(n)，然后将 f(n) 的最高阶系数、低阶和常量都去掉，得到函数 g(n)，那么算法的时间量度记作：T(n)=O(g(n))，它表示随问题规模 n 的增大，算法执行时间的增长率和 g(n) 的增长率相同，称做算法的渐近时间复杂度，简称时间复杂度（Time Complexity）</span>**

### 时间复杂度分析举例

对于上例这种较简单的算法，可以直接计算出算法中所有语句的频度，但对于稍微复杂一些的算法，则通常是比较困难的，即便能够给出，也可能是个非常复杂的函数

因此，为了客观地反映一个算法的执行时间，可以只用算法中的 “**<span style="font-weight:bold">基本语句</span>**” 的频度来度量算法的工作量。所谓 “基本语句” 指的是算法中重复执行次数和算法的执行时间成正比的语句，它对算法运行时间的贡献最大，比如：

![image/png](https://wechatapppro-1252524126.cdn.xiaoeknow.com/appvpmptkl94774/image/b_u_61a2357cb8665_QQ2rVIin/zqbs7bmkovr8dq.png?imageView2/2/q/100|imageMogr2/ignore-error/1)

这个算法的 “基本语句” 就是第 6 行，它是执行次数最多的语句，也就是对算法运行时间的贡献最大，它的频度是 n<sup>2</sup>，那么，我们就可以直接得到这个算法的时间复杂度是 O(n<sup>2</sup>)

分析算法时间复杂度的基本方法为：

- 找出所有语句中语句频度最大的那条语句作为基本语句
- 计算基本语句的频度得到输入数据规模 n 的某个函数 f(n)
- 如果 f(n) 有最高阶系数、低阶和常量，都去掉，得到 g(n)，就得到算法的时间复杂度 O(g(n))

实际上，如果算法的执行时间不随问题规模 n 的增加而增长，算法中语句频度就是某个常数。即使这个常数再大，算法的时间复杂度都是 O(1)。例如，上面的程序作如下改动：

#### 例 4：立方阶

![image/png](https://wechatapppro-1252524126.cdn.xiaoeknow.com/appvpmptkl94774/image/b_u_61a2357cb8665_QQ2rVIin/on5sg4mkovt55a.png?imageView2/2/q/100|imageMogr2/ignore-error/1)

显见，该程序段中频度最大的语句是（5），这条最深层循环内的基本语句的频度，依赖于各层循环变量的取值，由内向外可分析出语句（5）的执行次数为：

![图片](http://wechatapppro-1252524126.cdn.xiaoeknow.com/appvpmptkl94774/image/default/cPTKi2p1769051733HG.png?imageView2/2/q/100|imageMogr2/ignore-error/1)

上面的式子实际上等于 1 + 3 + 6 + 10 + 15 + ...

> 这个序列每一项都是由前一项加这一项所在的位置得到的，因此可以使用递推的方法求和
> 具体而言，假设这个序列的第 n 项为 a(n)，那么可以得到下面的递推式：
> a(1) = 1
> a(n) = a(n-1) + n
> 根据这个递推式，我们可以逐次计算出这个序列的各项值：
> a(1) = 1
> a(2) = a(1) + 2 = 3
> a(3) = a(2) + 3 = 6
> a(4) = a(3) + 4 = 10
> a(5) = a(4) + 5 = 15
> ...
> 因此，这个序列的前 n 项和可以表示为：S(n) = a(1) + a(2) + a(3) + ... + a(n-1) + a(n)
> 将递推式代入上式中，得到：S(n) = 1 + (1+2) + (1+2+3) + ... + (1+2+3+...+(n-1)) + (1+2+3+...+n)
> 简化括号内的表达式，得到：S(n) = n * (n+1) / 2 + n * (n+1) * (2n+1) / 6
> 合并同类项，化简得到：S(n) = n * (n+1) * (n+2) / 6

因此，语句（5）的执行次数为：n * (n+1) * (n+2) / 6。去掉最高阶系数、低阶和常量，得到该算法的时间复杂度为 T(n)=O(n<sup>3</sup>)，称为立方阶

#### 例 5：对数阶

![image/png](https://wechatapppro-1252524126.cdn.xiaoeknow.com/appvpmptkl94774/image/b_u_61a2357cb8665_QQ2rVIin/go1y1amkovul17.png?imageView2/2/q/100|imageMogr2/ignore-error/1)

设循环体内三条基本语句的频度为 f(n)，那么有：

- 第 1 次，i = 1 = 2^0
- 第 2 次，i = 1 * 2 = 2 = 2^1
- 第 3 次，i = 2 * 2 = 4 = 2^2
- 第 4 次，i = 4 * 2 = 8 = 2^3
- 第 5 次，i = 8 * 2 = 18 = 2^4
- ...
- 第 f(n) 次，i = 2^(f(n) - 1)

要执行第 f(n) 次的话，必须要有 2^(f(n) - 1) <= n，得到 f(n) <= 1 + log<sub>2</sub>n，所以算法的时间复杂度为 T(n) = O(log<sub>2</sub>n)，称为对数阶；这里采用的是**<span style="font-weight:bold">归纳法</span>**，来寻找规律，对于稍微复杂点的算法，可以使用这样的方法来求时间复杂度

再来看一段代码：

![image/png](https://wechatapppro-1252524126.cdn.xiaoeknow.com/appvpmptkl94774/image/b_u_61a2357cb8665_QQ2rVIin/84dfvpmkovuye0.png?imageView2/2/q/100|imageMogr2/ignore-error/1)

设循环体内两条基本语句的频度为 f(n)，那么有：

- 第 1 次，i = 1 = 3^0
- 第 2 次，i = 1 * 3 = 3 = 3^1
- 第 3 次，i = 3 * 3 = 9 = 3^2
- 第 4 次，i = 9 * 3 = 27 = 3^3
- ...
- 第 f(n) 次，i = 3^(f(n) - 1)

要执行第 f(n) 次的话，必须要有 3^(f(n) - 1) <= n，得到 f(n) <= 1 + log<sub>3</sub>n，所以算法的时间复杂度为 T(n) = O(log<sub>3</sub>n)

但是，因为 log<sub>3</sub>n = (log<sub>3</sub>2)*(log<sub>2</sub>n)，也就是说 O(log<sub>3</sub>n) = O((log<sub>3</sub>2)*(log<sub>2</sub>n))，而 log<sub>3</sub>2 是一个常量，在计算时间复杂度时需要去掉，所以 O(log<sub>3</sub>n) = O(log<sub>2</sub>n)，由此，我们可以得出结论：O(log<sub>2</sub>n) = O(log<sub>3</sub>n) = O(log<sub>4</sub>n) =... = O(log<sub>m</sub>n)  ，<span style="color:rgb(36, 41, 47)">也就是说，以任意数为底的对数阶复杂度都是相等的，因此，在对数阶时间复杂度的表示方法中，我们忽略对数的底，统一表示为 O(logn)</span>

### 常见时间复杂度

常见的时间复杂度按数量级递增排列依次为：常量阶 O(1)、对数阶 O(log<sub>2</sub>n)、线性阶 O(n)、线性对数阶 O(nlog<sub>2</sub>n)、平方阶 O(n<sup>2</sup>)、立方阶 O(n<sup>3</sup>)、……、k 次方阶 O(n<sup>k</sup>)、指数阶  O(2<sup>n </sup>) 等，即 O(1) < O(log₂n) < O(n) < O(nlog₂n) < O(n²) < O(n³) < O(2<sup>n</sup>) < O(n!) < O(n<sup>n</sup>)

不同数量级的时间复杂度性状如下图所示

![图片](http://wechatapppro-1252524126.cdn.xiaoeknow.com/appvpmptkl94774/image/default/cRtnJbj1769051733zZ.png?imageView2/2/q/100|imageMogr2/ignore-error/1)

一般情况下，随着 n 的增大，T(n) 的增长较慢的算法为较优的算法，显然，时间复杂度为指数阶 O(2<sup>n</sup>) 的算法效率极低，当 n 值稍大时就无法应用。应该尽可能选择使用多项式阶 O(n<sup>k</sup>) 的算法，而避免使用指数阶的算法

对于某些问题的算法，其基本语句的频度不仅仅与问题的规模相关，还依赖于其他因素。在此仅举一例来说明：

![image/png](https://wechatapppro-1252524126.cdn.xiaoeknow.com/appvpmptkl94774/image/b_u_61a2357cb8665_QQ2rVIin/0164pomkovw0zz.png?imageView2/2/q/100|imageMogr2/ignore-error/1)

容易看出，此算法中语句（2）的频度不仅与问题规模 n 有关，还与输入实例中数组 a[i] 的各元素值及 e 的取值有关

假设在数组 a[i] 中必定存在值等于 e 的元素，则查找必定成功，且 for 循环内的语句的频度将随被找到的元素在数组中出现的位置不同而不同

**<span style="font-weight:bold">①  最好情况</span>**：每次要找的值与 e 相同的元素恰好就是数组中的第一个元素，则不论数组的规模多大，语句（2）的执行次数 f(n)=1，此时时间复杂度为 O(1)

**<span style="font-weight:bold">② 最坏情况</span>**：每次待查找的都是数组中最后一个元素，则语句（2）的执行次数 f(n)=n，此时时间复杂度为 O(n)

**<span style="font-weight:bold">③ 平均情况：</span>**对于一个算法来说，需要考虑各种可能出现的情况，以及每一种情况出现的概率，一般情况下，可假设待查找的元素在数组中所有位置上出现的可能性均相同，则可取语句（2）的执行次数在最好情况与最坏情况下的平均值，即 f(n)=n/2，作为它的度量。此时时间复杂度为 O(n)

此例说明，算法的时间复杂度不仅与问题的规模有关，还与问题的其他因素有关。再如某些排序的算法，其执行时间与待排序记录的初始状态有关

因此，有时会对算法有最好、最坏以及平均时间复杂度的评价

- 称算法在最好情况下的时间复杂度为**<span style="font-weight:bold">最好时间复杂度</span>**，指的是算法计算量可能达到的最小值
- 称算法在最坏情况下的时间复杂度为**<span style="font-weight:bold">最坏时间复杂度</span>**，指的是算法计算量可能达到的最大值
- 算法的平均时间复杂度是指算法在所有可能情况下，按照输入实例以等概率出现时，算法计算量的**<span style="font-weight:bold">加权平均值</span>**

对算法时间复杂度的度量，人们更关心的是最坏情况下和平均情况下的时间复杂度。然而在很多情况下，算法的平均时间复杂度难于确定。因此，通常只讨论算法在最坏情况下的时间复杂度，即分析在最坏情况下，算法执行时间的上界。在本书后面内容中讨论的时间复杂度，除特别指明外，**<span style="font-weight:bold">均指最坏情况下的时间复杂度</span>**

### <span style="font-weight:bold;color:rgb(36, 41, 47)">空间复杂度</span>

算法的空间复杂度 S(n) 定义为该算法所需的存储空间，它是输入数据规模 n 的函数，记为：S(n)=O(g(n))

一个程序在执行时除需要存储空间来存放本身所用的指令、常数、变量和输入数据外，还需要一些对数据进行操作的工作单元和存储一些为实现计算所需信息的辅助空间。若输入数据所占空间只取决于问题本身，和算法无关，则只需分析除输入和程序之外的额外空间

例如，若算法中新建了几个与输入数据规模 n 相同的辅助数组，则空间复杂度为 O(n)。算法原地工作是指算法所需的辅助空间为常量，即 O(1)

## 线性表的顺序存储 - 顺序表

### 线性表的顺序存储表示

线性表的顺序表示指的是**<span style="font-weight:bold;text-decoration:underline">用一组地址连续的存储单元依次存储线性表的数据元素</span>**，这种表示也称作线性表的顺序存储结构或顺序映像。通常，称这种存储结构的线性表为顺序表（Sequential List）。其特点是，**<span style="font-weight:bold;text-decoration:underline">逻辑上相邻的数据元素，其物理次序也是相邻的</span>**

![图片](http://wechatapppro-1252524126.cdn.xiaoeknow.com/appvpmptkl94774/image/default/cwJwtIt1790040803qS.png?imageView2/2/q/100|imageMogr2/ignore-error/1)

看上图的线性表 a 中的每个元素都是 int 类型，它在主存储器中顺序存储，并且每个元素占 4 字节，从第 1 个元素开始依次顺序保存在地址为 8、12、16、20... 的存储单元中，其中第 1 个元素的地址 8 就是这个顺序表的**基地址（首地址）**，第 i 个元素在主存中地址 = 首地址 + (i - 1) × 每个元素占存储空间大小，比如上图中第 5 个元素（17）在主存中地址 = 8 + (5 - 1) × 4 = 24，可以看到，**<span style="font-weight:bold;text-decoration:underline">每一个数据元素的存储位置都和线性表的起始位置相差一个常数，这个常数和数据元素在线性表中的位序成正比</span>**。由此，只要确定了存储线性表的起始位置，线性表中任一数据元素都可随机存取，所以**<span style="font-weight:bold;text-decoration:underline">线性表的顺序存储结构是一种随机存取的存储结构</span>**

## 线性表的链式存储 - 单链表

线性表链式存储结构的特点是：**<span style="font-weight:bold;text-decoration:underline">用一组任意的存储单元存储线性表的数据元素</span>**（这组存储单元可以是连续的，也可以是不连续的）。因此，为了表示每个数据元素 ai 与其直接后继数据元素 ai+1 之间的逻辑关系，对数据元素 ai 来说，除了存储其本身的信息之外，还需存储一个指示其直接后继的信息（即直接后继的存储位置）。这两部分信息组成数据元素 ai 的存储映像，称为**<span style="font-weight:bold;text-decoration:underline">结点（node），它包括两个域：其中存储数据元素信息的域称为数据域；存储直接后继存储位置的域称为指针域</span>**

根据链表结点所含指针个数、指针指向和指针连接方式，可将链表分为单链表、循环链表、双向链表、二叉链表、十字链表、邻接表、邻接多重表等。其中单链表、循环链表和双向链表用于实现线性表的链式存储结构，其他形式多用于实现树和图等非线性结构。接下来先讨论单链表

### 单链表的定义和表示

下图（a）所示为线性表的单链表存储结构，整个链表的存取必须从头指针开始进行，**<span style="font-weight:bold;text-decoration:underline">头指针指示链表中第一个结点（即第一个数据元素的存储映像，也称首元结点）的存储位置</span>**。同时，由于最后一个数据元素没有直接后继，则单链表中最后一个结点的指针为空（NULL）。用单链表表示线性表时，数据元素之间的逻辑关系是由结点中的指针指示的。换句话说，**<span style="font-weight:bold;text-decoration:underline">指针为数据元素之间的逻辑关系的映像，则逻辑上相邻的两个数据元素其存储的物理位置不要求紧邻</span>**，由此，这种存储结构为非顺序映像或链式映像。通常将链表画成用箭头相链接的结点的序列，结点之间的箭头表示链域中的指针。上图（a）所示的单链表可画成如上图（c）所示的形式，这是因为在使用链表时，关心的只是它所表示的线性表中数据元素之间的逻辑顺序，而不是每个数据元素在存储器中的实际位置

![图片](http://wechatapppro-1252524126.cdn.xiaoeknow.com/appvpmptkl94774/image/default/chf9WpT1790040919HC.png?imageView2/2/q/100|imageMogr2/ignore-error/1)

由上述可见，单链表可由头指针唯一确定，在 C 语言中可用 "结构指针" 来描述，看上图（b），这里定义的是单链表中每个结点的存储结构，它包括两部分：

- ①  存储结点的数据域 data，其类型用通用类型标识符 ElemType 表示
- ② 存储后继结点位置的指针域 next，其类型为指向结点的指针类型 LNode *

为了提高程序的可读性，在此对同一结构体指针类型起了两个名称，LinkList 与 LNode *，两者本质上是等价的（看上图 a 的 LinkList head 和 LNode *head 是等价的）。**<span style="font-weight:bold;text-decoration:underline">通常习惯上用 LinkList 定义单链表，强调定义的是某个单链表的头指针</span>**；**<span style="font-weight:bold;text-decoration:underline">用 LNode * 定义指向单链表中任意结点的指针变量</span>**。例如，若定义 LinkList L，则 L 为单链表的头指针（简称该链表为表 L），若定义 LNode *p，则 p 为指向单链表中某个结点的指针，用 *p 代表该结点。当然也可以使用定义 LinkList p，这种定义形式完全等价于 LNode *p

注意区分指针变量和结点变量两个不同的概念，若定义 LinkList p 或 LNode *p，则 p 为指向某结点的指针变量，表示该结点的地址；而 *p 为对应的结点变量，表示该结点的名称

### 为什么要加头结点？

我们先来搞清楚头指针、首元结点、头结点这三者的区别：

- **<span style="font-weight:bold;text-decoration:underline">首元结点是指链表中存储第一个数据元素 a1 的结点</span>**。如下图所示的结点 14

![图片](http://wechatapppro-1252524126.cdn.xiaoeknow.com/appvpmptkl94774/image/default/corshTf1790040919wX.png?imageView2/2/q/100|imageMogr2/ignore-error/1)

- **<span style="font-weight:bold;text-decoration:underline">头结点是在首元结点之前附设的一个结点，其指针域指向首元结点</span>**。看上图的第一个节点就是头结点，头结点的数据域可以不存储任何信息，也可存储与数据元素类型相同的其他附加信息，例如，当数据元素为整数型（即当 ElemType 是 int）时，头结点的数据域中可存放该线性表的长度
- **<span style="font-weight:bold;text-decoration:underline">头指针是指向链表中第一个结点的指针</span>**。若链表设有头结点（看上图），则头指针所指结点为线性表的头结点；若链表不设头结点，则头指针所指结点为该线性表的首元结点

为什么要加一个头结点呢？主要有两个好处：

- ① 便于首元结点的处理
- ② 便于空表和非空表的统一处理

我们分别来看

#### 便于首元结点的处理

如果没有头结点的话，删除下面的首元结点和非首元结点的逻辑就不一样

## 循环单链表

循环链表（Circular Linked List）是另一种形式的链式存储结构。其特点是**<span style="font-weight:bold;text-decoration:underline">表中最后一个结点的指针域指向头结点，整个链表形成一个环</span>**。由此，从表中任一结点出发均可找到表中其他结点，下图所示为单链的循环链表

- 在单链表中，判别条件为 p != NULL 或 p->next != NULL
- 而循环单链表的判别条件为 p != L 或 p->next != L（看上图）

在某些情况下，若在循环链表中设立尾指针而不设头指针（见下图（a）），可使一些操作简化。例如，将两个线性表合并成一个表时，**<span style="font-weight:bold;text-decoration:underline">仅需将第一个表的尾指针指向第二个表的第一个结点，第二个表的尾指针指向第一个表的头结点，然后释放第二个表的头结点</span>**

- LNode *p = tail2->next->next，记住上图（a）第二个循环单链表的首元结点（即结点 2）

- tail1->next = p，将第一个表的尾指针指向第二个表的首元结点

- tail1 = tail2，将两个尾指针都指向新的合并之后的循环单链表的尾结点

## 双向链表

### 双向链表的表示

前面我们讨论的都是单链表，每个结点一个指示直接后继的指针域，从某个结点出发只能顺着指针向后寻查其他结点，在单链表中，查找直接后继结点的时间复杂度为 O(1)，若要寻查结点的直接前驱，则必须从表头指针出发，所以查找直接前驱结点的时间复杂度为 O(n)，这个效率就不高了，为克服单链表这种单向性的缺点，可利用双向链表，在双向链表中，每个结点除了存储元素值之外，还有两个指针域，**<span style="font-weight:bold;text-decoration:underline">一个指向直接后继，另一个指向直接前驱</span>**，使用 C 语言的结构体来描述的话，就是下图右上角这样的

![图片](http://wechatapppro-1252524126.cdn.xiaoeknow.com/appvpmptkl94774/image/default/caLbunH1790041057Ta.png?imageView2/2/q/100|imageMogr2/ignore-error/1)

对于双向链表，也可以有一个头结点，头结点的直接后继指向下一个结点，直接前驱指向空；下一个结点的直接前驱指向头结点，直接后继指向后一个结点，后一个节点的直接前驱指向前一个结点，这样就构成了一个双向链表，头指针 L 指向头结点，对于双向链表中的某个结点，**<span style="font-weight:bold;text-decoration:underline">这个结点的直接后继结点的直接前驱结点就是结点 p 本身</span>**，**<span style="font-weight:bold;text-decoration:underline">这个结点的直接前驱结点的直接后继结点也是结点 p 本身（即 p->next->prior = p->prior->next = p）。</span>**双向链表中直接通过 p->next 就可以访问结点的直接后继结点，时间复杂度是 O(1)，同样，直接通过 p->prior 就可以访问结点的直接前驱结点，时间复杂度也是 O(1)，这样就高效了，从一个结点也可以往后遍历链表，也可以往前遍历链表

### 双向链表的操作

在双向链表中，有些操作（如 ListLength、GetElem 和 LocateElem 等）仅需涉及一个方向的指针，则它们的算法描述和单链表的操作相同，但在插入、删除时有很大的不同，在双向链表中需同时修改两个方向上的指针

## 顺序表和链表的比较

前面介绍了线性表的两种存储结构：顺序表和链表。在实际应用中，不能笼统地说哪种存储结构更好，由于它们各有优缺点，选用哪种存储结构，则应根据具体问题作具体分析，通常从空间性能和时间性能两个方面作比较分析

### 空间性能的比较

#### （1）存储空间的分配

**<span style="font-weight:bold;text-decoration:underline">顺序表的存储空间必须预先分配</span>**，元素个数扩充受一定限制，易造成存储空间浪费或空间溢出现象；而**<span style="font-weight:bold;text-decoration:underline">链表不需要为其预先分配空间</span>**，只要内存空间允许，链表中的元素个数就没有限制。基于此，**<span style="font-weight:bold;text-decoration:underline">当线性表的长度变化较大，难以预估存储规模时，宜采用链表作为存储结构</span>**

#### （2）存储密度的大小

链表的每个结点除了设置数据域用来存储数据元素外，还要额外设置指针域，用来存储指示元素之间逻辑关系的指针，从存储密度上来讲，这是不经济的。所谓**<span style="font-weight:bold;text-decoration:underline">存储密度是指数据元素本身所占用的存储量和整个结点结构所占用的存储量之比</span>**，即：

![图片](http://wechatapppro-1252524126.cdn.xiaoeknow.com/appvpmptkl94774/image/default/cPklf3b1790041170FV.png?imageView2/2/q/100|imageMogr2/ignore-error/1)

存储密度越大，存储空间的利用率就越高。显然，顺序表的存储密度为 1，而链表的存储密度小于 1。如果每个元素数据域占据的空间较小，则指针的结构性开销就占用了整个结点的大部分空间，这样存储密度较小。例如，若单链表的结点数据均为整数，指针所占用的空间和整型量相同（假设都是 4B），则单链表的存储密度为 0.5。因此，如果不考虑顺序表中的空闲区，则顺序表的存储空间利用率为 100%，而单链表的存储空间利用率仅为 50%。基于此，**<span style="font-weight:bold;text-decoration:underline">当线性表的长度变化不大，易于事先确定其大小时，为了节约存储空间，宜采用顺序表作为存储结构</span>**

### 时间性能的比较

接下来，我们从时间方面来对比顺序表和链表，下面的表格总结了顺序表和单链表的这 7 种基本操作的时间复杂度。我们先来看修改操作和随机查询操作，其实就是对应的存数据和取数据，顺序表的存取元素的时间复杂度都是 O(1) 非常的高效，而链表的存取元素的时间复杂度都是 O(n) 相对低效很多，这是因为：

- 顺序表是由数组实现的，它是一种随机存取结构，指定任意一个位置序号 i，然后进行简单的地址计算，就可以在 O(1) 时间内直接存取该位置上的元素，即取值操作的效率高
- 而链表是一种顺序存取结构，按位置访问链表中第 i 个元素时，只能从表头开始依次向后遍历链表，直到找到第 i 个位置上的元素，时间复杂度为O(n)，即取值操作的效率低

基于此，**<span style="font-weight:bold;text-decoration:underline">若线性表的主要操作是和元素位置紧密相关的这类存取操作，很少做插入或删除时，宜采用顺序表作为存储结构</span>**

![图片](http://wechatapppro-1252524126.cdn.xiaoeknow.com/appvpmptkl94774/image/default/cvfQQsz1790041170r2.png?imageView2/2/q/100|imageMogr2/ignore-error/1)

为什么有很多插入或者删除操作时，不能采用顺序表作为存储结构呢？接下来，我们来看下插入操作和删除操作，从上表的时间复杂度这个角度上看，顺序表和链表的插入和删除操作的时间复杂度都是 O(n)，效率是一样的：

- 对于顺序表，要在第 i 个位置插入元素，首先要将第 i 个位置及其后面的元素往后移动一位，然后插入，这个时间复杂度是 O(n)
- 而对于链表，要在第 i 个位置插入一个结点，需要从头结点开始，往后一个一个遍历，找到第 i - 1 个结点，这个查找的过程时间复杂度是 O(n)，接下来是插入新结点的操作，只需要做两次指针的赋值操作，这个时间复杂度是 O(1)，所以说**<span style="font-weight:bold;text-decoration:underline">链表的插入和删除操作分为两部分</span>**，**<span style="font-weight:bold;text-decoration:underline">首先是查找到前面的节点，这个时间复杂度是 O(n)，然后就是插入或者删除操作，这个时间复杂度是 O(1)</span>**

如果已经确定了结点元素，比如在顺序表中的某个元素的后面插入一个新元素，那么还是要将后面的元素往后移动一位，然后插入，这个时间复杂度仍然是 O(n)；但是在链表中，如果是已经确定在这个结点的后面插入一个结点，那么只需要做两次简单的指针变量赋值就可以完成插入操作，不需要查找，也不需要移动数据，这个时间复杂度是 O(1)，这是非常的高效的

所以说，对于链表，在确定插入或删除的位置后，插入或删除操作无需移动数据，只需要修改指针，时间复杂度为 O(1)；而对于顺序表，进行插入或删除时，平均要移动表中近一半的结点，时间复杂度为 O(n)，如果每个结点的信息量较大时，比如每个元素存放的是学生的基本信息，或者存放图书等信息，移动结点的时间开销就更大了，所以说，**<span style="font-weight:bold;text-decoration:underline">对于频繁进行插入或删除操作的线性表，宜采用链表作为存储结构</span>**

## 栈（stack）的特点

栈也属于线性结构，它具有线性结构的基本特点，除第一个元素无直接前驱，最后一个元素无直接后继之外，其他每个数据元素都有一个前驱和后继，不过**<span style="font-weight:bold;text-decoration:underline">栈是一种操作受限的线性结构</span>**，比如一个线性结构，我们可以在它的两端进行删除和插入操作，比如删除表头元素，删除表尾元素，你也可以往表头插入一个元素，往表尾插入一个元素，而**<span style="font-weight:bold;text-decoration:underline">栈只能在一端进行删除和插入操作</span>**

![图片](http://wechatapppro-1252524126.cdn.xiaoeknow.com/appvpmptkl94774/image/default/cE0OxCx1790041328qB.png?imageView2/2/q/100|imageMogr2/ignore-error/1)

比如规定只能在表尾删除和插入（上图的上面），这种数据结构称为栈，**<span style="font-weight:bold;text-decoration:underline">可以删除和插入的这一端称为栈顶，不能操作的另一端则称为栈底</span>**，当然，也可以规定只能从表头进行插入和删除（上图的下面），这时表头就是栈顶，而表尾就是栈底，为了方便理解记忆栈，很多时候，我们将栈竖起来画，看下图

![图片](http://wechatapppro-1252524126.cdn.xiaoeknow.com/appvpmptkl94774/image/default/cd1UvMp1790041328Cj.png?imageView2/2/q/100|imageMogr2/ignore-error/1)

将元素从栈顶插入，这个操作称为进栈或者说入栈（push），将元素从栈顶删除，这个操作称为出栈（pop），在栈底的元素称为栈底元素，处于栈顶的元素称为栈顶元素，比如上面的栈中栈顶元素是 a4，栈底元素是 a1，这四个元素进栈的顺序是 a1、a2、a3、a4，如果要出栈的话，肯定是栈顶元素先出栈，所以出栈的顺序和进栈的顺序刚好相反，是 a4、a3、a2、a1，也就是最后进栈的元素，最先出栈，因此**<span style="font-weight:bold;text-decoration:underline">栈又称为后进先出（Last In First Out，LIFO）</span>**的线性表

### 卡特兰数 (Catalan) 公式

假设**<span style="font-weight:bold;text-decoration:underline">入栈顺序一定，但是出栈顺序可以不一定</span>**，比如入栈顺序是 a1、a2、a3、a4：

- 首先 a1 入栈，然后 a1 出栈，然后 a2 入栈，然后 a2 出栈，然后 a3 入栈，然后 a3 出栈，然后 a4 入栈，然后 a4 出栈，这样，出栈顺序和入栈顺序是一样的
- 再比如，可以 a1 入栈，a2 入栈，然后 a2 出栈，a3 入栈，a3 出栈，a4 入栈，a4 出栈，这时的出栈顺序是 a2、a3、a4、a1
- 再比如，可以 a1 入栈，a2 入栈，a3 入栈，然后 a3 出栈，a4 入栈，a4 出栈，a2 出栈，a1 出栈，这时的出栈顺序是 a3、a4、a2、a1

这里有一个栈的数学性质，当 n 个不同元素进栈时，出栈元素不同排列的个数为下图（a），这个公式称为**<span style="font-weight:bold;text-decoration:underline">卡特兰数 (Catalan) 公式</span>**，可采用数学归纳法证明，如何证明，我们不需要关心，记住这个公式即可

### 312 模式

前面我们使用卡特兰数公式可以计算出 n 个不同元素入栈序列的不同出栈序列数，对于一个入栈序列，肯定也存在不可能的出栈序列，**<span style="font-weight:bold;text-decoration:underline">比如入栈序列是 1、2、3，那么 3、1、2 就不可能是对应的出栈序列</span>**，因为第一个出栈的是 3，那么需要先将 1、2、3 依次压入栈，现在可以出栈 3，接下来只能出栈 2，不可能出栈 1，所以 3、1、2 就不可能是入栈序列 1、2、3 的出栈序列，**<span style="font-weight:bold;text-decoration:underline">这个就是经典的栈可生成性问题中禁止出现的排列，简称 312 模式。</span>**通用的 312 模式描述是这样描述的：**<span style="font-weight:bold;text-decoration:underline"> 若有 3 个数满足 a < b < c，出栈顺序是 c 最先，然后 a，最后 b， 也就是出栈子序列 (c, a, b) （即 312 模式），只要序列里存在这种三元组，就不可能是合法栈输出序列</span>**

来看一个例子，假设某个用例程序会进行一系列入栈和出栈的混合栈操作。人栈操作会将整数 0 到 9 按顺序压入栈；出栈操作会打印出返回值。下面哪种序列是不可能产生的？

（a）4 3 2 1 0 9 8 7 6 5

（b）4 6 8 7 5 3 2 9 0 1

（c）2 5 6 7 4 8 9 3 1 0

（d）0 4 6 5 3 8 1 7 2 9

（e）1 4 7 9 8 6 5 3 0 2

如果出栈序列中包含三元组**<span style="font-weight:bold;text-decoration:underline">（a, b, c） 中 a < b < c 且 c 最先被弹出，a 第二被弹出，b 第三被弹出</span>**，那么这个出栈序列是不可能产生的：

- **<span style="font-weight:bold;text-decoration:underline">对于（a）4 3 2 1 0 9 8 7 6 5</span>****：**不存在 312 模式，所以（a）可能是正确的出栈序列
- **<span style="font-weight:bold;text-decoration:underline">对于（b）4 6 8 7 5 3 2 9 0 1</span>**：存在三元组（0, 1, 2），2 先弹出，然后 0 弹出，最后是 1 弹出，这就是 312 模式，即（b）存在 312 模式，不可能是合理的出栈序列，当然这个出栈序列不止一个 312 模式，比如（0, 1, 3）也是 312 模式
- **<span style="font-weight:bold;text-decoration:underline">对于（c）2 5 6 7 4 8 9 3 1 0</span>****：**不存在 312 模式，所以（c）可能是正确的出栈序列
- **<span style="font-weight:bold;text-decoration:underline">对于（d）0 4 6 5 3 8 1 7 2 9</span>**：存在三元组（1, 2, 3），3 先弹出，然后 1 弹出，最后是 2 弹出，这就是 312 模式，即（d）存在 312 模式，不可能是合理的出栈序列
- **<span style="font-weight:bold;text-decoration:underline">对于（e）1 4 7 9 8 6 5 3 0 2</span>**：存在三元组（0, 2, 4），4 先弹出，然后 0 弹出，最后是 2 弹出，这就是 312 模式，即（e）存在 312 模式，不可能是合理的出栈序列

下面我们可以证明 312 模式：**<span style="font-weight:bold;text-decoration:underline">若借助栈由入栈序列 1、2、3、...、n（即栈是单调递增的，入栈的值肯定比之前入栈的值要大），得到的出栈序列为 p1、p2、...、pn（它是入栈序列的一个排列），则在出栈序列中不可能出现这样的情形：存在着 i < j < k  使得 pj < pk < pi（i 表示入栈序列第 i 个值，pi 表示出栈序列第 i 个值）</span>**

现在**<span style="font-weight:bold;text-decoration:underline">假设 j < k</span>**（这个时候 pj 比 pk 先出栈），存在下面两种规则：

- **<span style="font-weight:bold;text-decoration:underline">规则 ①：如果 pj < pk，则我们必须在 pk 压入栈之前，把 pj 出栈</span>**，因为入栈序列是自增的，要使的后面出栈的值（pk）大于前面出栈的值（pj），那么在 pk 入栈之前必须把 pj 出栈；如果在 pk 压栈之前没有把 pj 出栈的话，那么 pk 肯定会在 pj 之前出栈，这个不符合 j < k 的条件
- **<span style="font-weight:bold;text-decoration:underline">规则 ②：如果 pj > pk，则我们必须把 pk 留在栈上，直到 pj 压入栈之后</span>**，因为入栈序列是自增的，要使的后面出栈的值（pk）小于前面出栈的值（pj），那么当比较小的值 pk 入栈后，要一直保留在栈中，直到比较大的值 pj 入栈之后，此时比较大的值 pj 先出栈，然后比较小的值 pk 后出栈；如果在 pj 入栈之前，就把 pk 出栈的话，那么不符合 j < k 的条件

把这两条规则结合起来，条件 i < j < k 和 pj < pk < pi 是不可能的：

- 首先 i < j 且 pi > pj 的话，根据上面的规则 ②，那么必须把 pj 留在栈上，直到 pi 入栈之后，也就是说 **<span style="font-weight:bold;text-decoration:underline">pj 必须在 pi 出栈后再出栈</span>**
- 然后 j < k 且 pj < pk 的话，根据上面的规则 ①，那么必须在 pk 压入栈之前，把 pj 出栈，也就是说 **<span style="font-weight:bold;text-decoration:underline">pj 必须在 pk 出栈之前先出栈</span>**
- 最后 i < k 且 pi > pk 的话，根据上面的规则 ②，那么必须把 pk 留在栈上，直到 pi 入栈之后，也就是说 **<span style="font-weight:bold;text-decoration:underline">pi 必须在 pk 出栈后再出栈</span>**

综上所述，条件 i < j < k 和 pj < pk < pi 意味着 pj 必须在 pk 出栈之前和在 pi 出栈之后再出栈，但是 pi 又必须在 pk 出栈后再出栈，这个很明显矛盾了，因此不可能存在 i < j < k 和 pj < pk < pi 这个情况

### 中缀表达式转后缀表达式

下面先给出一种由中缀表达式转后缀表达式的手算方法：

1. 按照运算符的运算顺序对所有运算单位加括号
2. 将运算符移至对应括号的后面，相当于按 "左操作数、右操作数、运算符" 重新组合
3. 去除所有括号

例如，中缀表达式 A+B*(C-D)-E/F 转后缀表达的过程如下 (下标表示运算符的运算顺序):

1. 加括号：((A+③(B*②(C-①D)))-⑤(E/④F))
2. 运算符后移：((A(B(CD)-①)*②)+③(EF)/④)-⑤
3. 去除括号后，得到后缀表达式：ABCD-①*②+③EF/④-⑤

在计算机中，**<span style="font-weight:bold;text-decoration:underline">中缀表达式转后缀表达式时需要借助一个栈</span>**，用于保存暂时还不能确定运算顺序的运算符。从左到右依次扫描中缀表达式中的每一项，具体转化过程如下：

1. 遇到操作数。直接加入后缀表达式
2. 遇到界限符。若为 "("，则直接入栈；若为 ")"，则依次弹出栈中的运算符，并加入后缀表达式，直到弹出 "(" 为止。注意，"(" 直接删除，不加入后缀表达式
3. 遇到运算符。**<span style="font-weight:bold;text-decoration:underline">若其优先级高于除 "(" 外的栈顶运算符，则直接入栈</span>**。否则，从栈顶开始，依次弹出栈中优先级高于或等于当前运算符的所有运算符，并加入后缀表达式，直到遇到一个优先级低于它的运算符或遇到 "(" 时为止，之后将当前运算符入栈

按上述方法扫描所有字符后，将栈中剩余运算符依次弹出，并加入后缀表达式，例如，中缀表达式 A+B*(C-D)-E/F 转后缀表达式的过程如下表所示：

## 栈和递归调用

### 函数调用栈

我们来看下图左边三个函数，首先是 main 函数，调用了 first 函数，first 函数调用了 second 函数，当 second 函数执行完，返回到 first 函数继续执行，当 first 函数执行完，再返回到 main 函数继续执行，main 函数执行完了，整个程序才算执行完了，你是不是发现了，最后调用的函数，先执行完，这是不是符合后进先出的特点呢？实际上，计算机系统在实现函数调用时，确实是使用了栈这种数据结构

![图片](http://wechatapppro-1252524126.cdn.xiaoeknow.com/appvpmptkl94774/image/default/cks2nqt1790041719XA.png?imageView2/2/q/100|imageMogr2/ignore-error/1)

在程序执行时，**<span style="font-weight:bold;text-decoration:underline">系统会在主存中为程序分配一个函数调用栈</span>**，看上图右边的函数调用栈一般是倒着的，也就是从高地址往低地址增长，每当一个函数执行时，都会创建一个栈帧，然后压入函数调用栈中，假设系统中的 init 函数调用的 main 函数，那么在函数调用栈中肯定存在 init 函数栈帧：

- 当执行 main 函数时，会为其生成一个栈帧压入函数调用栈中，在这个栈帧中，有返回地址，用于回到调用 main 函数的 init 函数，还有 main 函数的局部变量
- 当 main 函数调用执行 first 函数时，也会为其生成一个栈帧压入函数调用栈中，栈帧中，有返回地址，用于返回到 main 函数，还有参数和局部变量等数据
- 当 first 调用执行 second 函数时，也会为其生成一个栈帧压入函数调用栈中，栈帧中，有返回地址，用于返回到 first 函数，还有参数和局部变量等数据

当 second 函数执行完，然后根据栈帧中的返回地址，回到 first 函数，然后系统将它对应的栈帧出栈，当 first 函数执行完，根据其对应栈帧中的返回地址，回到 main 函数中，然后系统将它对应的栈帧出栈；当 main 函数执行完，根据其对应栈帧中的返回地址，回到 init 函数中，然后系统将它对应的栈帧出栈，这样**<span style="font-weight:bold;text-decoration:underline">通过函数调用栈完成了函数调用的实现，因为函数调用栈是系统创建并初始化的，所以，我们也称之为系统调用栈</span>**

### 递归过程与递归工作栈

一个递归函数的运行过程类似于多个函数的嵌套调用，只是**<span style="font-weight:bold;text-decoration:underline">调用函数和被调用函数是同一个函数</span>**，因此，和每次调用相关的一个重要概念是递归函数运行的 "层次"。假设调用该递归函数的主函数为第 0 层，则从主函数调用递归函数为进入第 1 层；从第 i 层递归调用本函数为进入"下一层"，即第 i+1 层。反之，退出第 i 层递归应返回至 "上一层"，即第 i−1 层。为了保证递归函数正确执行，系统需**<span style="font-weight:bold;text-decoration:underline">设立一个 "递归工作栈" 作为整个递归函数运行期间使用的数据存储区（递归工作栈其实就是系统函数调用栈）</span>**。每一层递归所需信息构成一个工作记录，其中包括所有的实参、所有的局部变量，以及上一层的返回地址。每进入一层递归，就产生一个新的工作记录压入栈顶。每退出一层递归，就从栈顶弹出一个工作记录，则当前执行层的工作记录必是递归工作栈栈顶的工作记录，称**<span style="font-weight:bold;text-decoration:underline">这个记录为 "活动记录"，活动记录其实就是上面说的栈帧</span>**

下面以下图所示的阶乘函数 fact(4) 为例，介绍递归过程中递归工作栈和活动记录（栈帧）的使用。当执行 fact(4) 之前，系统会初始化一个递归工作栈（其实就是系统函数调用栈）：

- 执行 fact(4) 时，系统为其生成一个栈帧， 在栈帧中，参数 n 的值是 4，但是局部变量 tmp 的值还不知道是多少，需要调用执行完函数 fact(3) 本身才知道
- 接下来执行 fact(3) 时，又会创建一个栈帧，这时栈帧的参数 n = 3，因为这里调用 fact 时，将 n - 1 的值，也就是 4 - 1 的值传给这些函数调用，这个栈帧中的 tmp 仍然不知道多少，需要调用执行完函数 fact(2) 才知道
- 接下来执行 fact(2) 时，又会创建一个栈帧，这时栈帧的参数 n = 2，tmp 仍然不知道多少，需要调用执行完函数 fact(1) 才知道
- 接下来执行 fact(1) 时，又会创建一个栈帧，这时栈帧的参数 n = 1，tmp 仍然不知道多少，需要调用执行完函数 fact(0) 才知道
- 接下来执行 fact(0) 时，又会创建一个栈帧，这时栈帧的参数 n = 0，执行到第一条语句就会返回值 1

这样就完成了递的过程，接下来是归的过程

![图片](http://wechatapppro-1252524126.cdn.xiaoeknow.com/appvpmptkl94774/image/default/clhemY51790041719EA.png?imageView2/2/q/100|imageMogr2/ignore-error/1)

- fact(0) 执行完，返回到 fact(1)，从递归工作栈中弹出栈顶的栈帧，然后将 fact(1) 栈帧中的 n=1 和 fact(0) 的返回值 1 相乘，得到 tmp = 1，然后返回 fact(1) 的结果 1
- fact(1) 执行完，返回到 fact(2)，从递归工作栈中弹出栈顶的栈帧，然后将 fact(2) 栈帧中的 n=2 和 fact(1) 的返回值 1 相乘，得到 tmp = 2，然后返回 fact(2) 的结果 2
- fact(2) 执行完，返回到 fact(3)，从递归工作栈中弹出栈顶的栈帧，然后将 fact(3) 栈帧中的 n=3 和 fact(2) 的返回值 2 相乘，得到 tmp = 6，然后返回 fact(3) 的结果 6
- fact(3) 执行完，返回到 fact(4)，从递归工作栈中弹出栈顶的栈帧，然后将 fact(4) 栈帧中的 n=4 和 fact(3) 的返回值 6 相乘，得到 tmp = 24，然后返回 fact(4) 的结果 24

这样，归的过程也完成了，得到 fact(4) = 24，之所以叫递归，是因为在函数执行时，有两个过程，**<span style="font-weight:bold;text-decoration:underline">一个是递的过程，递的过程主要是执行递归调用之前的程序代码</span>**，上面就是判断 n 的值是不是 0；**<span style="font-weight:bold;text-decoration:underline">第二个是归的过程，归的过程主要执行递归调用之后的程序代码</span>**，上面就是执行 n 乘以 tmp，以后，我们在看递归代码的时候，都可以将其分为递和归这两个过程

### 哪些问题可以使用递归解决

#### 问题 ①：定义是递归的

首先，如果你要解决的问题，可以定义为一个函数，而且这个函数的定义都是递归的，比如**<span style="font-weight:bold;text-decoration:underline">下图上面求某个整数 n 的阶乘</span>**，就可以定义为这样一个函数，当 n = 0 时，值是 1，当 n > 0 时，那么n 的阶乘等于 n 乘以 n - 1 的阶乘。这个函数的定义很明显是递归的，所以可以使用递归调用来实现，写一个递归函数 fact，参数是 n，求 n 的阶乘。实现时，判断如果 n == 0（递归终止条件），直接返回 1，否则，返回 n 乘以 n - 1 的阶乘，要求 n - 1 的阶乘，递归调用函数本身，参数设置为 n - 1 即可

![图片](http://wechatapppro-1252524126.cdn.xiaoeknow.com/appvpmptkl94774/image/default/c7gT49V1790041719W3.png?imageView2/2/q/100|imageMogr2/ignore-error/1)

再比如**<span style="font-weight:bold;text-decoration:underline">上图下面求斐波那契数列</span>**，这个函数的定义也是递归的，当 n 等于 1 或者 2 的时候，斐波那契数是 1，其他情况下，第 n 个斐波那契数等于第 n - 1 个斐波那契数加上第 n - 2 个斐波那契数。可以先定义一个递归函数 fib，参数是 n，求第 n 个斐波那契数，如果 n 等于 1 或者 2，则直接返回 1，这个是递归终止条件，否则的话，则递归调用 fib(n - 1) 和 fib(n - 2)，将他们的值相加就得到第 n 个斐波那契数

对于这个递归调用，我们还可以这样来理解，比如说，我们要求 4 的阶乘，我们把求 4 的阶乘看成是一个大问题，要解决这个这问题，我们可以将它拆成一个问题规模更小的子问题，也就是求 3 的阶乘，看下图，如果这个子问题解决了，大问题就解决了，比如说我们已经求到了 3 的阶乘的值，那么将它乘以 4 就得到了 4 的阶乘的值

![图片](http://wechatapppro-1252524126.cdn.xiaoeknow.com/appvpmptkl94774/image/default/co21cAK1790041719s7.png?imageView2/2/q/100|imageMogr2/ignore-error/1)

- 接下来就是要**<span style="font-weight:bold;text-decoration:underline">求 3 的阶乘</span>**这个子问题，可以继续将其拆成规模更小的子问题，也就是求 2 的阶乘，如果这个子问题（求 2 的阶乘）解决了，那么这个大一点的子问题（求 3 的阶乘）就可以解决，将 3 乘以 2 的阶乘就是它的结果
- 接下来就是要**<span style="font-weight:bold;text-decoration:underline">求 2 的阶乘</span>**这个子问题，可以继续将其拆成规模更小的子问题，也就是求 1 的阶乘，如果这个子问题解决了，那么这个大一点的子问题就可以解决，将 2 乘以 1 的阶乘就是它的结果
- 接下来就是要**<span style="font-weight:bold;text-decoration:underline">求 1 的阶乘</span>**这个子问题，可以继续将其拆成规模更小的子问题，也就是求 0 的阶乘，如果这个子问题解决了，那么这个大一点的子问题就可以解决，将 1 乘以 0 的阶乘就是它的结果
- 而 **<span style="font-weight:bold;text-decoration:underline">0 的阶乘是已知的，就是 1，这个我们称为最小子问题</span>**，一般而言最小子问题的解是已知的

所以说，如果一个问题符合这三个条件，那么就可以使用递归来解决：

- ① **<span style="font-weight:bold;text-decoration:underline">首先问题可以拆成若干个子问题</span>**，就比如刚刚求阶乘的大问题就可以拆成若干个子问题
- ② **<span style="font-weight:bold;text-decoration:underline">其次是子问题的求解方式和大问题求解方式是一样的</span>**，就比如刚刚求阶乘，所有的子问题和大问题的求解方式都是一样，都是调用这个递归函数就可以解决，它们不同的是参数而已
- **<span style="font-weight:bold;text-decoration:underline">③  最后是一定要存在结果已知的最小子问题</span>**，比如求阶乘的最小子问题就是 n 等于 0 的时候

以后，分析问题时，如果符合这三个条件，那么就可以使用递归来解决，对于类似这种的复杂问题，若能够分解成几个相对简单且解法相同或类似的子问题来求解，便称作递归求解。例如上图，计算 4! 时先计算 3!，然后再进一步分解进行求解，这种分解-求解的策略叫做 "分治法"，分治法求解递归问题算法的一般形式为：

#### 问题 ②：数据结构是递归的

某些数据结构本身具有递归的特性，则它们的操作可递归地描述。例如，对于链表，其结点 LNode 的定义由数据域 data 和指针域 next 组成，而指针域 next 是一种指向 LNode 类型的指针，即 LNode 的定义中又用到了其自身，所以**<span style="font-weight:bold;text-decoration:underline">链表是一种递归的数据结构</span>**。对于递归的数据结构，相应算法采用递归的方法来实现特别方便。链表的创建和链表结点的遍历输出都可以采用递归的方法

### 递归算法的效率分析

#### 时间复杂度

在算法分析中，当一个算法中包含递归调用时，其时间复杂度的分析可以转化为一个递归方程求解。实际上，这个问题是数学上求解渐近阶的问题，而递归方程的形式多种多样，其求解方法也不一而足。**<span style="font-weight:bold;text-decoration:underline">迭代法是求解递归方程的一种常用方法，其基本步骤是迭代地展开递归方程的右端，使之成为一个非递归的和式</span>**，**<span style="font-weight:bold;text-decoration:underline">然后通过对和式的估计来达到对方程左端（即方程的解）的估计</span>**

![图片](http://wechatapppro-1252524126.cdn.xiaoeknow.com/appvpmptkl94774/image/default/c40AUrG1790041719Ey.png?imageView2/2/q/100|imageMogr2/ignore-error/1)

下面以上图的阶乘递归函数 fact(n) 为例，说明通过迭代法求解递归方程来计算时间复杂度的方法。设 fact(n) 的执行时间是 T(n)。此递归函数中语句 if(n==0) return 1 的执行时间是 O(1)，递归调用 fact(n-1) 的执行时间是 T(n-1)，所以 return n*fact(n-1) 的执行时间是 O(1) + T(n-1)，其中，设两数相乘的执行时间为 O(1)，则对某常数 C、D 有如下递归方程：

![图片](http://wechatapppro-1252524126.cdn.xiaoeknow.com/appvpmptkl94774/image/default/cMhhHy41790041719Kh.png?imageView2/2/q/100|imageMogr2/ignore-error/1)

设 n>2，利用上式对 T(n-1) 展开，即在上式中用 n-1 代替 n 得到 T(n-1)=C+T(n-2) 再代入 T(n)=C+T(n-1) 中，有 T(n)=2C+T(n-2) 同理，当 n>3 时有 T(n)=3C+T(n-3) 依次类推，当 n>i 时有 T(n)=iC+T(n-i)，最后，当 i=n 时有 T(n) = nC + T(0) = nC+D，求得递归方程的解为 T(n)=O(n)

再来看上图的斐波那契数列 fib(n) 为例，通过上面的迭代法求解递归方程 fib(n) 来计算时间复杂度，此递归函数中语句 if(n==1 || n==2) return 1 的执行时间是 O(1)，递归调用 fib(n-1) 的执行时间是 T(n-1)，fib(n - 2) 的执行时间是 T(n-2)，所以 return fib(n-1) + fib(n - 2) 的执行时间是 O(1) + T(n - 1) + T(n-2)，其中，设两数相加的执行时间为 O(1)，则对某常数 C、D 有如下递归方程：

![图片](http://wechatapppro-1252524126.cdn.xiaoeknow.com/appvpmptkl94774/image/default/cmpU6mB1790041720Su.png?imageView2/2/q/100|imageMogr2/ignore-error/1)

设 n>2，T(n) = C + T(n-1) + T(n-2) = C + (C + T(n-2) + T(n-3)) + (C + T(n-3) + T(n-4))

= C + 2C + T(n-2) + 2T(n-3) + T(n-4)

= C + 2C + (C + T(n-3) + T(n-4)) + 2(C + T(n-4) + T(n-5)) + (C + T(n-5) + T(n-6))

= C + 2C + 4C + T(n-3)  + 3T(n-4) + 3T(n-5) + T(n-6)

= C + 2C + 4C + (C + T(n-4) + T(n-5)) + 3(C + T(n-5) + T(n-6)) + 3(C + T(n-6) + T(n-7)) + (C + T(n-7) + T(n-8))

= C + 2C + 4C + 8C + T(n-4) + 4T(n-5) + 6T(n-6) + 4T(n-7) + T(n-8)

= C + 2C + 4C + 8C + ... + 2<sup>n-1</sup>C  （前面式子中 T 最终都等于常数 D，计算时间复杂度时省略常数 D）

= 2<sup>n</sup>C，（省略掉常数 C，得到时间复杂度 T(n) = O(2<sup>n</sup>)）

根据上面的分析方法，同样可以得到上面 Hanoi 塔问题的时间复杂度也是 O(2<sup>n</sup>)

#### 空间复杂度

递归函数在执行时，系统需设立一个 "递归工作栈" 存储每一层递归所需的信息，此工作栈是递归函数执行的辅助空间，因此，分析递归算法的空间复杂度需要分析工作栈的大小

对于递归算法，空间复杂度 S(n)=O(f (n))，其中，f(n) 为 "递归工作栈" 中栈帧的个数与问题规模 n 的函数关系。根据这种分析方法不难得到，前面讨论的阶乘问题、Fibonacci 数列问题、Hanoi 塔问题的递归算法的空间复杂度均为 O(n)

### 利用栈将递归转换为非递归的方法

通过上述讨论，可以看出递归程序在执行时需要系统提供隐式栈这种数据结构来实现，对于一般的递归过程，仿照递归算法执行过程中递归工作栈的状态变化可直接写出相应的非递归算法。这种利用栈消除递归过程的步骤如下：

- （1）设置一个工作栈存放递归工作记录（包括实参、返回地址及局部变量等）
- （2）进入非递归调用入口（即被调用程序开始处）将调用程序传来的实参和返回地址入栈（递归程序不可以作为主程序，因而可认为初始是被某个调用程序调用）
- （3）进入递归调用入口：当不满足递归结束条件时，逐层递归，将实参、返回地址及局部变量入栈，这一过程可用循环语句来实现 - 模拟递归分解的过程
- （4）递归结束条件满足，将到达递归出口的给定常数作为当前的函数值
- （5）返回处理：在栈不空的情况下，反复退出栈顶记录，根据记录中的返回地址进行题意规定的操作，即逐层计算当前函数值，直至栈空为止 - 模拟递归求值过程

通过以上步骤，**<span style="font-weight:bold;text-decoration:underline">可将任何递归算法改写成非递归算法</span>**。但改写后的非递归算法和原来比较起来，结构不够清晰，可读性差，有的还需要经过一系列的优化，这里不再举例详述，具体示例参下一章中二叉树中序遍历的非递归算法

## 队列的顺序表示

和栈一样，队列也是操作受限的线性表，我们知道栈的特点是后进先出，而队列和栈相反，队列是先进先出（First In First Out，FIFO）的线性表，看下图，**<span style="font-weight:bold;text-decoration:underline">在队列中，只允许在表的一端进行插入，而在另一端删除元素，允许插入的一端称为队尾（rear），允许删除的一端则称为队首（front）</span>**

![图片](http://wechatapppro-1252524126.cdn.xiaoeknow.com/appvpmptkl94774/image/default/cFPr3wD1790041779uz.png?imageView2/2/q/100|imageMogr2/ignore-error/1)

当往队列中插入元素，只能从队尾插入，这个我们称为入队；要删除元素的话，只能从队头删除，这个我们称为出队，可以看出先进来的元素，先出去了，这就是先进先出，就和日常排队打饭一个道理，先排的肯定先打饭。队列也有两种存储表示，顺序表示和链式表示，先来看顺序表示

### 队列的顺序存储表示

和顺序栈相类似，在队列的顺序存储结构中，除了用一组地址连续的存储单元依次存放从队列头到队列尾的元素之外，还需附设两个整型变量 front 和 rear 分别指示队列头元素及队列尾元素的位置（后面分别称为头指针和尾指针）。队列的顺序存储结构表示如下：

![图片](http://wechatapppro-1252524126.cdn.xiaoeknow.com/appvpmptkl94774/image/default/cj5x81T1790041779kP.png?imageView2/2/q/100|imageMogr2/ignore-error/1)

为了在 C 语言中描述方便起见，在此约定：**<span style="font-weight:bold;text-decoration:underline">初始化创建空队列时，令 front = rear = 0，每当插入新的队列尾元素时，尾指针 rear 增 1；每当删除队列头元素时，头指针 front 增1</span>**。因此，**<span style="font-weight:bold;text-decoration:underline">在非空队列中，头指针始终指向队列头元素，而尾指针始终指向队列尾元素的下一个位置</span>**。看下图所示：

![图片](http://wechatapppro-1252524126.cdn.xiaoeknow.com/appvpmptkl94774/image/default/cX0UK7J1790041779yU.png?imageView2/2/q/100|imageMogr2/ignore-error/1)

假设当前队列分配的最大空间为 6（即 capacity = 6），则当队列处于上图（d）所示的状态时不可再继续插入新的队尾元素，否则会出现溢出现象，即因数组越界而导致程序的非法操作错误。事实上，**<span style="font-weight:bold;text-decoration:underline">此时队列的实际可用空间并未占满，所以这种现象称为 "假溢出"</span>**。这是由 "队尾入队，队头出队" 这种受限制的操作造成的，怎样解决这种 "假溢出" 问题呢？一个较巧妙的办法是将顺序队列变为一个环状的空间，如下图所示，称之为循环队列

![图片](http://wechatapppro-1252524126.cdn.xiaoeknow.com/appvpmptkl94774/image/default/cG3cQYD17900417792U.png?imageView2/2/q/100|imageMogr2/ignore-error/1)

头、尾指针以及队列元素之间的关系不变，只是在循环队列中，头、尾指针 "依环状增 1" 的操作可用 "模" 运算来实现。通过取模，头指针和尾指针就可以在顺序表空间内以头尾衔接的方式 "循环" 移动。在下图（a）中，队头元素是 J5，在元素 J6 入队之前，在 Q->rear 的值为 5，当元素 J6 入队之后，通过 "模" 运算，**<span style="font-weight:bold;text-decoration:underline">Q->rear = (Q->rear + 1) % 6，得到 Q->rear 的值为 0</span>**，而不会出现前面图（d）的 "假溢出" 状态

![图片](http://wechatapppro-1252524126.cdn.xiaoeknow.com/appvpmptkl94774/image/default/c0tgCMG1790041779bS.png?imageView2/2/q/100|imageMogr2/ignore-error/1)

在上图（b）中，J7、J8、J9、J10 相继入队，则队列空间均被占满，此时头、尾指针相同。在上图（c）中，若 J5 和 J6 相继从上图（a）所示的队列中出队，使队列此时呈 "空" 的状态，头、尾指针的值也是相同的。由此可见，对于循环队列不能以头、尾指针的值是否相同来判别队列空间是 "满" 还是 "空"。在这种情况下，如何区别队满还是队空呢？通常有以下两种处理方法

![图片](http://wechatapppro-1252524126.cdn.xiaoeknow.com/appvpmptkl94774/image/default/cO5GE8i1790041952nR.png?imageView2/2/q/100|imageMogr2/ignore-error/1)

我们来思考一个问题，对于一个双端队列，如何由入队序列 a,b,c,d 得到出队序列 d,c,a,b，这个有很多种方法，我们来看其中一个方法，比如，a 左入、b 右入、c 右入、d 右入，然后 d 右出、c 右出、a 左出、b 左出，这样就得到了出队序列 d c a b，当然，还有其他的方法，你可以思考下

## 二维数组

因为在计算机中一般是用二维数组来存储矩阵，因此，在看特殊矩阵压缩存储之前，我们先来看看二维数组。下图是一个 int 类型的一维数组：

![图片](http://wechatapppro-1252524126.cdn.xiaoeknow.com/appvpmptkl94774/image/default/cz1CKIe1790041997gM.png?imageView2/2/q/100|imageMogr2/ignore-error/1)

通过下面公式可以计算得到每个数组元素的内存地址：

- **<span style="font-weight:bold;text-decoration:underline">公式一：data[i] 的内存地址 = 数组 data 的基地址 + i * 元素占用内存大小</span>**

拿到数组元素的内存地址，就可以直接访问内存中的元素了，所以，根据下标访问数组元素的时间复杂度是 O(1)

注：这里的数组基地址、元素的内存地址都是虚拟内存地址，CPU 拿到元素的虚拟地址，首先需要转换成物理地址，然后将物理地址送到 CPU Cache，如果未命中 Cache，就将物理地址送到物理内存中，从物理内存中加载对应元素到 Cache 和 CPU 寄存器中

下图是一个 4 × 3 的二维数组（4 行 3 列），它是**<span style="font-weight:bold;text-decoration:underline">按行优先存储</span>**在内存中：

![图片](http://wechatapppro-1252524126.cdn.xiaoeknow.com/appvpmptkl94774/image/default/ctQLeod1790041997Ba.png?imageView2/2/q/100|imageMogr2/ignore-error/1)

对于一个 m 行 n 列的二维数组，假设每个元素占内存大小是 L 个字节，那么可以通过下面公式可以计算得到每个数组元素的内存地址：

- **<span style="font-weight:bold;text-decoration:underline">公式二：a[i][j] 的内存地址 = 数组 a 的基地址 + (n * i + j) * L</span>**

下图是一个 4 × 3 的二维数组（4 行 3 列），它是**<span style="font-weight:bold;text-decoration:underline">按列优先存储</span>**在内存中：

## 对称矩阵

如果一个 n 阶矩阵中的元满足 a[i][j] = a[j][i]（1 ≤ i，j ≤ n），那么称为 n 阶对称矩阵，比如下图是一个 n 阶对称矩阵：

![图片](http://wechatapppro-1252524126.cdn.xiaoeknow.com/appvpmptkl94774/image/default/cSDB33m1790042049wL.png?imageView2/2/q/100|imageMogr2/ignore-error/1)

一个 n 阶矩阵可以分为上三角区和下三角区，对于 n 阶对称矩阵的上下三角区是对称的，看下图：

![图片](http://wechatapppro-1252524126.cdn.xiaoeknow.com/appvpmptkl94774/image/default/cNsQDE91790042049z0.png?imageView2/2/q/100|imageMogr2/ignore-error/1)

**<span style="font-weight:bold;text-decoration:underline">对于对称矩阵，可以为每一对对称元分配一个存储空间，则可将 n^2 个元压缩存储到 n(n+1)/2 个元的空间中。</span>**比如只存储下三角区的元，那么需要存储空间的个数可以这么算：

- 第 1 行需要存储 1 个元
- 第 2 行需要存储 2 个元
- 第 3 行存储存储 3 个元
- ......
- 第 n 行需要存储 n 个元

所以，总共需要存储空间的个数是 1 + 2 + 3 + ... + n = n(n+1)/2，那么可以申请一个长度为 n(n+1)/2 的一维数组

### 按行优先存储下三角区

**<span style="font-weight:bold;text-decoration:underline">按行优先存储</span>**上面的对称矩阵的下三角区所有的元，如下图：

![图片](http://wechatapppro-1252524126.cdn.xiaoeknow.com/appvpmptkl94774/image/default/cEzdElQ17900420492y.png?imageView2/2/q/100|imageMogr2/ignore-error/1)

上图是按行优先存储下三角区的元素，先存储第一行的 a11，再存储第二行的 a21 和 a22，接下来再存储第三行的 a31、a32 和 a33，......，最后存储最后一行 an1、an2、...、ann。这样考点就来了，这个时候 408 比较喜欢考察根据矩阵中的 i 和 j 的值求对应的 k 的值，或者根据 k 的值求对应的 i 和 j 的值。比如，现在求矩阵中的 a59（i = 5，j = 9） 应该存储在一维数组中的哪个位置呢？

首先，一定要看清题目哈，这里采用的是**<span style="font-weight:bold;color:rgb(222, 60, 54);text-decoration:underline">按行优先</span>****<span style="font-weight:bold;text-decoration:underline">存储对称矩阵的</span>****<span style="font-weight:bold;color:rgb(222, 60, 54);text-decoration:underline">下三角区</span>**，那么一维数组中存储的元素对应的 i 和 j 的值的关系是 i ≥ j，而 a59 的 i 是小于 j 的（位于上三角区），所以，a59 的元素不会直接存储在一维数组中。因为是对称矩阵，所以 a59 = a95 的，而 a95 的元素是直接存储在一维数组中的，所以，要求 a59（i = 5，j = 9） 应该存储在一维数组中的哪个位置，其实就是求 a95 应该存储在哪个位置？那么，只要求出在下三角区内，a95 的前面有多少个元素即可。a95 的前面有 8 行，元素总数是 (1 + 2 + 3 + 4 + 5 + 6 + 7 + 8) = 8(1 + 8) / 2 = 36，在第 9 行中，a95 的前面又有 4 个元素，所以 a95 的前面一共有 36 + 4 = 40 个元素，那么 a95 在一维数组中的下标 k = 40

注意，一维数组下标 k 是从 0 开始的，而矩阵的 i 和 j 都是从 1 开始的

现在问你 aij （i ≤ j）应该存储在一维数组哪个位置呢？求解过程是这样的：首先，确定一维数组是**<span style="font-weight:bold;color:rgb(222, 60, 54);text-decoration:underline">按行优先</span>****<span style="font-weight:bold;text-decoration:underline">存储对称矩阵的</span>****<span style="font-weight:bold;color:rgb(222, 60, 54);text-decoration:underline">下三角区</span>**的，然后，因为 i ≤ j，所以 aij 的元素直接存储在一维数组中，只要求 aij 前面有多少个元素即可：

- aij 前面有 i - 1 行，包含的元素个数为 1 + 2 + 3 + ... + i - 1 = i (i - 1) / 2
- 在第 i 行，aij 的前面有 j - 1 个元素

所以，在下三角区中，aij 的前面的元素个数为 i (i - 1) / 2 + j - 1，即一维数组的下标 k = i (i - 1) / 2 + j - 1

现在如果是 i ＞ j 的话，那么 aij 应该存储在一维数组哪个位置呢？因为是对称矩阵，所以 aij = aji，也就是要求在下三角区中 aji 前面有多少个元素即可：

- aji 前面有 j - 1 行，包含的元素个数为 1 + 2 + 3 + ... + j - 1 = j (j - 1) / 2
- 在第 j 行，aji 的前面有 i - 1 个元素

所以，在下三角区中，aji 的前面的元素个数为 j (j - 1) / 2 + i - 1，即一维数组的下标 k = j (j - 1) / 2 + i - 1

上面我们是根据 i 和 j 的值，求 k 的值，有的时候还会考你根据 k 的值来求 i 和 j 的值，我们还是以下图（**<span style="font-weight:bold;color:rgb(222, 60, 54);text-decoration:underline">按行优先</span>****<span style="font-weight:bold;text-decoration:underline">存储对称矩阵的</span>****<span style="font-weight:bold;color:rgb(222, 60, 54);text-decoration:underline">下三角区</span>**）为例：

![图片](http://wechatapppro-1252524126.cdn.xiaoeknow.com/appvpmptkl94774/image/default/cUEcl971790042049kZ.png?imageView2/2/q/100|imageMogr2/ignore-error/1)

比如现在告诉你 k = 34，那么它对应矩阵中的哪个元呢？也就是说对应的 i 和 j 的值是多少呢？首先，下标 k = 34 的话，那么这个元素的前面有 34 个元素，接下来，我们要做的就是确定这个元素在对称矩阵中下三角区的哪一行哪一列。我们可以假设 k = 34 这个元素位于第 i 行，那么前 i - 1 行的元素个数 = i(i - 1) / 2，而前 i 行的元素个数 = i (i + 1) / 2，那么<span style="color:rgb(222, 60, 54);text-decoration:underline">前 i - 1 行的元素个数肯定小于等于 34，而前 i 行的元素个数肯定大于 34，即 i(i - 1) / 2 ≤ 34 ＜ i (i + 1) / 2</span>，即 i(i - 1) ≤ 68 < i(i + 1)，那么 i = 8

即 k = 34 这个元素位于第 8 行（i = 8），那么前 7 行的元素个数为 8 * (8 - 1) / 2 = 28，那么在第 8 行中，k = 34 这个元素的前面还有 34 - 28 = 6 个元素，那么 j = 7。所以 k = 34 这个元素位于第 8 行的第 7 个元素，即 i = 8，j = 7，当然，因为是对称矩阵，a87 = a78，所以 k = 34 这个元素可以对应着 a78（即 i = 7，j = 8）这个元素

### 按列优先存储下三角区

上面，我们讨论的是<span style="color:rgb(222, 60, 54);text-decoration:underline">按行优先</span>存储对称矩阵的<span style="color:rgb(222, 60, 54);text-decoration:underline">下三角区</span>，接下来，我们再来讨论**<span style="font-weight:bold;text-decoration:underline">按列优先</span>**存储对称矩阵的下三角区，看下图：

![图片](http://wechatapppro-1252524126.cdn.xiaoeknow.com/appvpmptkl94774/image/default/cJlV2Ud17900420497W.png?imageView2/2/q/100|imageMogr2/ignore-error/1)

可以看到，先存储第一列 a11、a21、...、an1，再存储第二列 a22、a32、...、an2，再存储第三列 a33、a43、...、an3，......，最后存储第 n 列 ann

<span style="color:rgb(222, 60, 54);text-decoration:underline">先来看 aij（i ≥ j）应该存储在一维数组的哪个位置呢？</span>只要求出 aij 前面有多少个元素即可。在按列优先存储的下三角区中，aij 前面包含的元素是：

- 第 1 列有 n 个元素
- 第 2 列有 n - 1 个元素
- 第 3 列有 n - 2 个元素
- 第 4 列有 n - 3 个元素
- ...
- 第 j - 1 列有 n - (j - 2) 个元素，即 n - j + 2 个元素
- 第 j 列有 i - j 个元素，即 aj,j、aj+1,j、...、ai-1,j，从 j 到 i - 1，即 (i - 1) - j + 1 = i - j 个元素

元素 aij 在第 j 列，其前 j - 1 列包含元素个数是 n + (n - 1) + (n - 2) + ... + (n - j + 2) = (j - 1) * (n + n - j + 2) / 2 = (j - 1) * (2n - j + 2)/2。在第 j 列中，aij 的前面有 i - j 个元素，所以 aij 前面总共包含元素个数是  (j - 1) * (2n - j + 2)/2 + i - j，即 k =  (j - 1) * (2n - j + 2)/2 + i - j

<span style="color:rgb(222, 60, 54);text-decoration:underline">再来看 aij（i < j）应该存储在一维数组的哪个位置呢？</span>只要求出 aji 前面有多少个元素即可。在按列优先存储的下三角区中，aji 前面包含的元素是：

- 第 1 列有 n 个元素
- 第 2 列有 n - 1 个元素
- 第 3 列有 n - 2 个元素
- 第 4 列有 n - 3 个元素
- ...
- 第 i - 1 列有 n - (i - 2) 个元素，即 n - i + 2 个元素
- 第 i 列有 j - i 个元素

元素 aji 在第 j 列，其前 i - 1 列包含元素个数是 n + (n - 1) + (n - 2) + ... + (n - i + 2) = (i - 1) * (2n - i + 2) / 2。在第 i 列中，aij 的前面有 j - i 个元素，所以 aji 前面总共包含元素个数是 (i - 1) * (2n - i + 2) / 2 + j - i，即 k =   (i - 1) * (2n - i + 2) / 2 + j - i

最后，来看下在按列优先存储对称矩阵的下三角区时，<span style="color:rgb(222, 60, 54);text-decoration:underline">如何根据一维数组下标 k 求出矩阵中的 i 和 j 的值？</span>假设 n = 10（即矩阵是 10 阶对称矩阵），其<span style="color:rgb(222, 60, 54);text-decoration:underline">下三角区按照列优先</span>存储在一维数组中，试求下标 k = 34 这个元素位于对称矩阵的哪一行哪一列呢？

可以假设下标 k = 34 这个元素位于第 j 列，那么：

- 前 j - 1 列包含的元素个数是 n + (n - 1) + (n - 2) + ... + (n - j + 2)  = (j - 1) * (2n - j + 2)/2 = (j - 1) * (22 - j) / 2
- 前 j 列包含的元素格式是 n + (n - 1) + (n - 2) + ... + (n - j + 1) = j * (2n -j + 1) / 2 = j * (21 - j) / 2

因为 k = 34，那么在下标为 34 的元素前面有 34 个元素，而 k = 34 这个元素位于第 j 列，所以，前 j - 1 列的元素总数必定小于等于 34，而前 j 列的元素总数必定大于 34，即 (j - 1) * (22 - j) / 2 ≤ 34 < j * (21 - j) / 2，得到  (j - 1) * (22 - j)  ≤ 68 < j * (21 - j)，得到 j = 5

也就是说 k = 34 的元素位于矩阵中的第 5 列（j = 5），前 j - 1 列中包含的元素个数是 (5 - 1) * (22 - 5) / 2 = 34。也就是说，前 4 列刚好是 34 个元素，那么在第 5 列中，k = 34 的元素前面包含 0 个元素，即 i - j = 0，因此 k = 34 的元素就位于第 5 列中的第 1 个元素，此时 i = j = 5

上面讨论的是：

- 按行优先存储对称矩阵的下三角区
- 按列优先存储对称矩阵的下三角区

题目还有可能考察：

- 按行优先存储对称矩阵的<span style="color:rgb(255, 0, 0);text-decoration:underline">上</span>三角区
- 按列优先存储对称矩阵的<span style="color:rgb(255, 0, 0);text-decoration:underline">上</span>三角区

这个做题思路和上面的存储下三角区情况是一样的，你一定要看清题目

## 三角矩阵

接下来看第二种特殊矩阵，三角矩阵，分为下三角矩阵和上三角矩阵，看下图：

- 下三角矩阵是指**<span style="font-weight:bold;text-decoration:underline">矩阵上三角（不包括对角线）中的元素均为常数 c 或零的 n 阶矩阵</span>**，比如下图（a）的上三角元素值都是常量 9
- 上三角矩阵是指**<span style="font-weight:bold;text-decoration:underline">矩阵下三角（不包括对角线）中的元素均为常数 c 或零的 n 阶矩阵</span>**，比如下图（b）的下三角元素值都是常量 9

![图片](http://wechatapppro-1252524126.cdn.xiaoeknow.com/appvpmptkl94774/image/default/ccYvA8x1790042085D1.png?imageView2/2/q/100|imageMogr2/ignore-error/1)

对于三角矩阵，我们可以像存储对称矩阵那样，只存储上三角或者下三角以及主对角线元素即可，比如下图**<span style="font-weight:bold;text-decoration:underline"> n 阶下三角矩阵</span>**，其中 c 是常量哈，如果**<span style="font-weight:bold;text-decoration:underline">按行优先</span>**存储到一维数组 b 中的话：

- 首先存储第 1 行，即保存 a1,1
- 然后存储第 2 行，即保存 a2,1、a2,2
- 然后存储第 3 行，即保存 a3,1、a3,2、a3,3
- 然后存储第 4 行，即保存 a4,1、a4,2、a4,3、a4,4
- .......
- 最后存储第 n 行的 n 个元素
- 然后还需要一个存储单元存储常量 c

所以说，**<span style="font-weight:bold;text-decoration:underline">存储一个三角矩阵，需要的一维数组 b 的长度是 n(n+1)/2 + 1</span>**

![图片](http://wechatapppro-1252524126.cdn.xiaoeknow.com/appvpmptkl94774/image/default/c3jTEBO1790042085YX.png?imageView2/2/q/100|imageMogr2/ignore-error/1)

在上图三角矩阵中，如果 i ≥ j 的话，那么 ai,j 对应的一维数组下标 k 就是 i(i-1) / 2 + j - 1；当 i < j，那么 k 等于最后一个元素的下标（即 n(n+1)/2）。再来看下图的**<span style="font-weight:bold;text-decoration:underline"> n 阶上三角矩阵</span>**，如果**<span style="font-weight:bold;text-decoration:underline">按行优先</span>**存储的话，先存储上三角区的第一行、再存储第 2 行、接下来第 3 行、第 4 行等等，最后存储第 n 行的一个元素 an,n

![图片](http://wechatapppro-1252524126.cdn.xiaoeknow.com/appvpmptkl94774/image/default/c22VIDl1790042085T3.png?imageView2/2/q/100|imageMogr2/ignore-error/1)

还需要一个存储单元存储常数  c，所以**<span style="font-weight:bold;text-decoration:underline">存储上图 n 阶上三角矩阵，需要的一维数组 b 的长度是 n(n+1)/2 + 1</span>**。在上图，对于上三角元素 ai,j（i ≤ j），其对应的下标 k 值是多少呢？可以采用归纳法来求：

- 第 1 行需存储 n 个元素
- 第 2 行需存储 n - 1 个元素
- 第 3 行需存储 n - 2 个元素
- ...
- 第 i - 1 行需存储 n - (i - 2) 个元素
- 第 i 行需存储 j - i 个元素，包含的元素是 ai,i、ai,i+1、...、ai,j-1

将上面的所有元素个数累加起来得到 n + (n - 1) + (n - 2) + ... + (n - (i - 2)) + (j - i) = (i - 1)(2n - i + 2) / 2 + j - i，这个结果也就是 ai,j （注意 i ≤ j）在一维数组 b 中的下标 k 的值（公式不要记，理解记住推导过程即可）。如果 i > j （即 ai,j 在下三角区），那么 k =  n(n+1)/2

## 对角矩阵

**<span style="font-weight:bold;text-decoration:underline">对角矩阵所有的非零元素都集中在以主对角线为中心的带状区域中</span>**，比如下图 n 阶矩阵，除了主对角线上和直接在对角线上、下方 a 条对角线上的元素之外，所有其他的元素皆为零

![图片](http://wechatapppro-1252524126.cdn.xiaoeknow.com/appvpmptkl94774/image/default/cPLtyB41790042125cD.png?imageView2/2/q/100|imageMogr2/ignore-error/1)

对于对角矩阵，我们主要来看三对角矩阵，对 n 阶矩阵 A 中的任意一个元素 ai,j ，当 |i - j| > 1 时，若有 ai,j = 0 (1≤i，j≤n)，则称为三对角矩阵

![图片](http://wechatapppro-1252524126.cdn.xiaoeknow.com/appvpmptkl94774/image/default/c7CxoUW1790042125es.png?imageView2/2/q/100|imageMogr2/ignore-error/1)

上图就是一个 n 阶三对角矩阵，在三对角矩阵中，**<span style="font-weight:bold;text-decoration:underline">所有非零元素都集中在以主对角线为中心的 3 条对角线的区域，其他区域的元素都为零</span>**。三对角矩阵，非零元素的分布有一个明显的规律，所以三对角矩阵也可以采用压缩存储，将 3 条对角线上的元素按行优先方式存放在一维数组 B 中

![图片](http://wechatapppro-1252524126.cdn.xiaoeknow.com/appvpmptkl94774/image/default/cIC0G0o1790042125w3.png?imageView2/2/q/100|imageMogr2/ignore-error/1)

看上图，首先存储第一行的两个元素（a1,1、a1,2）、 然后存储第 2 行的 3 个元素（a2,1、a2,2、a2,3）、然后存储第 3 行的 3 个元素（a3,2、a3,3、a3,4）、...、然后存储第 n - 1 行的 3 个元素、最后存储第 n 行的 2 个元素。**<span style="font-weight:bold;text-decoration:underline">在三对角矩阵中，第一行和最后一行分别有 2 个元素，其他行都有 3 个元素，所以一维压缩数组 B 的大小是 3n - 2</span>**，那么在三对角中的元素 ai,j（注意 |i - j| ≤ 1），对应一维数组 B 中的下标 k 等于多少呢？同样，采用归纳法来推导，来看看 ai,j 前面有多少个非零元素：

- 第 1 行需存储 2 个元素
- 第 2 行需存储 3 个元素
- 第 3 行需存储 3 个元素
- ... （中间的每行都是存储 3 个元素）
- 第 i - 1 行，也是存储 3 个元素
- 第 i 行，需存储 j - i + 1 个元素，怎么来的呢？对于第 i 行有三种情况：

所以第 i 行中，在 ai,j 之前的元素个数是 j - i + 1，现在将上面前 i 行所有元素个数累加得到 2 + 3 * (i - 2) + j - i + 1 = 2i + j - 3，**<span style="font-weight:bold;text-decoration:underline">即 ai,j 对应一维数组 B 中的下标 k = 2i + j - 3</span>**

反之，若已知三对角矩阵中的某个元素 ai,j 存放在一维数组 B 的下标是 k，如何推导出这个元素在三对角矩阵中的位置呢（即如何根据 k 求 i 和 j）？在三对角矩阵中，因为除了第 1 行只有 2 个元素，其他中间行都是有 3 个元素，所以**<span style="font-weight:bold;text-decoration:underline">将 (k + 1) / 3 + 1 就可以得到行号 i</span>**：

- 比如 k = 3，那么 i = (3 + 1) / 3 = 1，再加 1，等于 2，即下标 k = 3 的元素位于第 2 行（看上图，确实是）
- 再比如 k =7，那么 i = (7 + 1) / 3 = 2，再加 1，等于 3，即下标 k = 7 的元素位于第 3 行（看上图，确实是）

然后将 i 的值代入这个公式 **<span style="font-weight:bold;text-decoration:underline"> k = 2i + j - 3</span>**，就可以求出 j = k - 2i + 3

## 稀疏矩阵

**<span style="font-weight:bold;text-decoration:underline">所谓稀疏矩阵，就是在矩阵中，其非零元素比零元素少很多，且分布没有一定规律</span>**

![图片](http://wechatapppro-1252524126.cdn.xiaoeknow.com/appvpmptkl94774/image/default/cJS0lzP1790042162GV.png?imageView2/2/q/100|imageMogr2/ignore-error/1)

比如上图矩阵，大部分是零，只有小部分是非零元素，而且非零元素的位置没有任何规律，这就是一个稀疏矩阵。对于如何高效存储稀疏矩阵有两种方法，分别是三元组表和十字链表

### 三元组表

因为非零元素的分布没有规律，所以**<span style="font-weight:bold;text-decoration:underline">仅存储非零元素的值是不够的，还要存储它所在的行和列</span>**，因此，将非零元素及其相应的行和列构成一个三元组，看下图的三元组表：

- 第一行记录着矩阵 A 中第 2 行第 3 列保存着非零元素 11
- 第二行记录着矩阵 A 中第 3 行第 6 列保存着非零元素 99
- 第二行记录着矩阵 A 中第 5 行第 4 列保存着非零元素 88
- ......

![图片](http://wechatapppro-1252524126.cdn.xiaoeknow.com/appvpmptkl94774/image/default/cQMJ7F71790042162tQ.png?imageView2/2/q/100|imageMogr2/ignore-error/1)

当我们拿到上图三元组表，还需要恢复这个稀疏矩阵，如果只有这个三元组表的话，是恢复不出来这个矩阵的。我们还需要知道：

- 这个**<span style="font-weight:bold;text-decoration:underline">矩阵的总行数和总列数</span>**，根据这个总行数和总列数，假设 m 是 9，n 是 8，那么就可以创建一个全部时 0 元素的 9 * 8 的矩阵
- 还得知道**<span style="font-weight:bold;text-decoration:underline">这个三元组表的长度 length</span>**，有了这个长度，我们就可以遍历这个三元组表，将里面的每个非零元素恢复到对应位置

这样，就可以恢复出所有的非零元素，进而恢复出了稀疏矩阵。如果用 C 代码来实现的话，可以定义两个结构体，下图结构体 Element 表示三元组，包含行号、列号和对应的额非零元素值，这个结构体就是表示三元组表中的每一行

![图片](http://wechatapppro-1252524126.cdn.xiaoeknow.com/appvpmptkl94774/image/default/cGVOKmW17900421629F.png?imageView2/2/q/100|imageMogr2/ignore-error/1)

然后再定义一个三元组表结构体 TripleTable（上图右边），用一个数组 table 来表示存储这个三元组表，然后使用 length 表示数组的长度，m 表示矩阵总行数，n 表示矩阵总列数

### 十字链表

使用十字链表存储稀疏矩阵时，可以**<span style="font-weight:bold;text-decoration:underline">将稀疏矩阵中所有的非零元素看成一个链表中的结点（下图矩阵的框框中都是非 0 元素）</span>**，我们定义下图结构体 OLNode 来表示一个非零元素结点，包括以下 5 个成员：

- 这个结点在矩阵中的行号和列号
- 非零元素值
- 指针 right 指向相同行中的下一个非零结点
- 指针 down 指向相同列中的下一个非零结点

相当于，每一行都是一个单链表，每一列都是一个单链表，行单链表和列单链表交叉成十字，所以称为十字链表

![图片](http://wechatapppro-1252524126.cdn.xiaoeknow.com/appvpmptkl94774/image/default/cWMl38o1790042162RV.png?imageView2/2/q/100|imageMogr2/ignore-error/1)

## 树和二叉树的性质

### 树的性质

**<span style="font-weight:bold;text-decoration:underline">性质 ①：树的结点数 n 等于所有结点的度数之和再加 1。</span>**在一棵树中，每个结点与它的每个孩子之间都是由一个分支相连，所以**<span style="font-weight:bold;text-decoration:underline">树中所有结点的度数之和等于树中分支数之和</span>**；在一棵树中，每个非根结点都通过一条分支和双亲相连，即所有每个非根结点都对应着唯一一条分支，而根结点因为没有双亲，所以根结点没有对应的分支，因此**<span style="font-weight:bold;text-decoration:underline">树的结点数 n = 分支总数 + 1。</span>**那么，根据：

- 树所有结点的度数之和 = 分支总数
- 树的结点数 n = 分支总数 + 1

就可以得到：树的结点数 n = 所有结点的度数之和 + 1。**<span style="font-weight:bold;text-decoration:underline">这个性质很容易出现在 408 考试中</span>**，我们思考一个题目：在一棵度为 4 的树 T 中，若有 20 个度为 4 的结点，10 个度为 3 的结点，1 个度为 2 的结点，10 个度为 1 的结点，则树 T 的叶结点个数是多少呢？

所有结点的度数之和 = 20 * 4 + 10 * 3 + 1 * 2 + 10 * 1 = 122（注意，叶结点的度为 0），然后树的结点数 n = 所有结点的度数之和 + 1 = 122 + 1 = 123，那么树 T 的叶结点个数 = 树的结点数 n - 分支结点个数 = 树的结点数 n - 度不为 0 的结点个数 =  123 - (20 + 10 + 1 + 10) = 123 - 41 = 82

度为 k 的结点，问该树中有多少个叶子结点？

根据上面性质 ① 树的结点数 n = 所有结点的度数之和 + 1 = n1 + n2 * 2 + n3 * 3 + ... + nk * k + 1，然后这棵树的非叶子结点数是 n1 + n2 + n3 + ... + nk，那么树的叶子结点数 = (n1 + n2 * 2 + n3 * 3 + ... + nk * k + 1) - (n1 + n2 + n3 + ... + nk) = n2 + n3 * 2 + n4 * 3 + ... + nk * (k - 1) + 1 =

再来看一个问题：已知在一棵含有 n 个结点的树中，只有度为 k 的分支结点和度为 0 的叶子结点。试求该树含有的叶子结点的数目

假设度为 k 的分支结点数是 nk，那么根据上面性质 ① 树的结点数 n = 所有结点的度数之和 + 1 = nk * k + 1，这样可以得到 nk = (n - 1) / k，那么叶子结点数 = 树的总结点数 - 度为 k 的分支结点数 = n - (n - 1) / k

证明：一棵满 k 叉树上的叶子结点数 n0 和非叶子结点数 n1 之间满足以下关系: n0 = (k-1) * n1 + 1

所谓满 k 叉树其实就是这棵树中只存在度为 k 的分支结点和度为 0 的叶子结点，根据上面性质 ① 树的结点数 n = 所有结点的度数之和 + 1 = k * n1 + 1，那么叶子结点数 n0 = k * n1 + 1 - n1 = (k - 1) * n1 + 1

**<span style="font-weight:bold;text-decoration:underline">性质 ②：度为 m 的树中第 i 层上最多有 m^(i - 1) 个结点（i ≥ 1）。</span>**度为 m 的树中，每个结点最多有 m 个子树，那么：

- 第 1 层，最多只有 1 个根结点，即 m^(1 - 1)
- 第 2 层，最多有 m 个结点，即 m^(2 - 1)
- 第 3 层，最多有 m * m 个结点，即 m^(3 - 1)
- 第 4 层，最多有 m * m * m 个结点，即 m^(4 - 1)
- 第 i 层，最多有 m^(i - 1) 个结点

其实就是每一层结点数都是最多的情况，这种情况的树称为满 m 叉树。如下图是度为 3 的树，其每层最多结点个数的情况：

**<span style="font-weight:bold;text-decoration:underline">性质 ③：高度为 h 度为 m 的树最多有 (m^h - 1) / (m - 1) 个结点。</span>**高度为 h 的满 m 叉树的结点数是最多的，结点总数等于 1 ~ h 层每层结点数之和，即：m^0 + m^1 + m^2 + ... + m^(h - 1) = (m^h - 1) / (m - 1)

这里是等比数列的求和，求和公式是：a1 * (1 - q^n) / (1 - q)，其中 a1 表示等比数列第一个数，q 表示公比，n 表示等比数列的数的个数

- 二叉树中的每个结点的度可以不是 2
- 度为 2 的树必定有一个结点的度是 2

可以这么说，度为 2 的树必定是二叉树，但是二叉树不一定是度为 2 的树，因此，二叉树和度为 2 的树的性质还是有一些区别的，请看下图：

- 度为 1 的分支则与 1 个分支相连，比如上图中结点 H 的度为 1，它和子结点 M 之间有一个分支相连
- 度为 0 的结点，则没有子结点，所以没有对应的分支

这样看的话，**<span style="font-weight:bold;text-decoration:underline">二叉树分支总数 B = 度为 1 的结点数 + 2 倍的度为 2 的结点数 = n1 + 2 * n2（式子 ③）。</span>**根据式子 ② 和式子 ③ 可以得到 n - 1 = n1 + 2 * n2，可以得到 n = n1 + 2 * n2 + 1，将其代入前面式子 ①，可以得到 n1 + 2 * n2 + 1 = n0 + n1 + n2，这样可以得到 n0 = n2 + 1，即**<span style="font-weight:bold;text-decoration:underline">二叉树中叶结点的个数 = 度为 2 的结点个数 + 1（这个公式需要理解并记住）</span>**
